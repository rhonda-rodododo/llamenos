## အမျိုးမျိုးသော Provider များဖြင့် တယ်လီဖုန်း

**5 သော အသံ Provider များ** — Twilio, SignalWire, Vonage, Plivo သို့မဟုတ် မိမိကိုယ်တိုင် Host လုပ်ထားသော Asterisk မှ ရွေးချယ်နိုင်သည်။ Admin Settings UI တွင် သို့မဟုတ် Setup Wizard အတွင်း Provider ကို ပြင်ဆင်နိုင်သည်။ ကုဒ်မည်းဖျက်ဘဲ မည်သည့်အချိန်မဆို Provider ပြောင်းနိုင်သည်။

**WebRTC Browser Calling** — စေတနာ့ဝန်ထမ်းများသည် ဖုန်းမလိုဘဲ Browser တွင် တိုက်ရိုက်ခေါ်ဆိုမှုများကို ဖြေကြားနိုင်သည်။ Twilio, SignalWire, Vonage နှင့် Plivo အတွက် Provider သီးခြား WebRTC Token ထုတ်ပေးခြင်း။ စေတနာ့ဝန်ထမ်းတစ်ဦးချင်းစီ၏ ခေါ်ဆိုမှုဦးစားပေးချက် ပြေကျင်းပေးနိုင်သည် (ဖုန်း၊ Browser သို့မဟုတ် နှစ်ခုလုံး)။

## ခေါ်ဆိုမှုလမ်းညွှန်

**တစ်ပြိုင်နက်ခေါ်သံ** — ခေါ်ဆိုသူဆက်သွယ်လာသောအခါ တာဝန်ကျနေပြီး မအားလပ်သော စေတနာ့ဝန်ထမ်းအားလုံး၏ ဖုန်းသည် တစ်ပြိုင်နက်ထဲ ဝင်လာသည်။ ပထမဆုံးအဖြေပေးသူသည် ခေါ်ဆိုမှုကိုရယူသည်။ ကျန်ခေါ်သံများသည် ချက်ချင်းရပ်တန့်သွားသည်။

**Shift အခြေခံအချိန်ဇယား** — သတ်မှတ်ထားသော နေ့ရက်နှင့် အချိန်များဖြင့် ပုံမှန် Shift များကို ဖန်တီးနိုင်သည်။ Shift များအတွင်း စေတနာ့ဝန်ထမ်းများကို ခန့်ထားနိုင်သည်။ စနစ်သည် တာဝန်ကျသည့်သူများဆီသို့ ခေါ်ဆိုမှုများကို အလိုအလျောက်လမ်းညွှန်ပေးသည်။

**စောင့်ဆိုင်းသီချင်းပါသော စီတန်း** — စေတနာ့ဝန်ထမ်းအားလုံး မအားလပ်ပါက ခေါ်ဆိုသူများသည် ပြင်ဆင်နိုင်သော စောင့်ဆိုင်းသီချင်းပါသော စီတန်းသို့ ဝင်ရောက်လာကြသည်။ စီတန်း Timeout ကို ပြေကျင်းနိုင်သည် (30-300 စက္ကန့်)။ မည်သူမျှ မဖြေကြားပါက ခေါ်ဆိုမှုများသည် Voice Mail သို့ သွားမည်ဖြစ်သည်။

**Voice Mail Fallback** — စေတနာ့ဝန်ထမ်း မည်သူမျှ မဖြေကြားပါက ခေါ်ဆိုသူများသည် အသံမှတ်တမ်း (အများဆုံး 5 မိနစ်) ထားနိုင်သည်။ အသံမှတ်တမ်းများကို Whisper AI ဖြင့် စာတမ်းရိုက်၍ Admin ပြန်လည်သုံးသပ်ရန် ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။

## ကုဗ္ဌအကာအကြယ်ထည့်ထားသော မှတ်စုများ

**End-to-End ကုဗ္ဌအကာအကြယ်ထည့်ထားသော မှတ်စုများ** — စေတနာ့ဝန်ထမ်းများသည် ခေါ်ဆိုမှုအတွင်းနှင့် ခေါ်ဆိုပြီးနောက် မှတ်စုများ ရေးသားကြသည်။ မှတ်စုများသည် Browser မှ မထွက်ခင် ECIES (secp256k1 + XChaCha20-Poly1305) ဖြင့် Client-Side တွင် ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။ Server သည် Ciphertext သာလျှင် သိမ်းဆည်းထားသည်။

**Double Encryption** — မှတ်စုတစ်ခုစီကို နှစ်ကြိမ် ကုဗ္ဌအကာအကြယ်ထည့်သည်။ တစ်ကြိမ်မှာ မှတ်စုရေးသားသူ စေတနာ့ဝန်ထမ်းအတွက်၊ တစ်ကြိမ်မှာ Admin အတွက် ဖြစ်သည်။ နှစ်ဦးလုံးသည် လွတ်လပ်စွာ ဖြည်ဖတ်နိုင်သည်။ အခြားမည်သူမျှမ ဖတ်နိုင်ပါ။

**စိတ်ကြိုက် Fields များ** — Admin များသည် မှတ်စုအတွက် စိတ်ကြိုက် Fields များကို သတ်မှတ်ပေးထားသည်။ စာသား၊ နံပါတ်၊ ရွေးချယ်မှု၊ Checkbox၊ စာသားဧရိယာ တို့ဖြစ်သည်။ Fields များသည် မှတ်စုအကြောင်းအရာနှင့် တွဲဖက်၍ ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။

**Draft အလိုအလျောက်သိမ်းဆည်းခြင်း** — မှတ်စုများကို Browser တွင် ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Draft အဖြစ် အလိုအလျောက်သိမ်းဆည်းထားသည်။ စာမျက်နှာ ပြန်လည်တင်ပါက သို့မဟုတ် စေတနာ့ဝန်ထမ်း ထွက်ခွာပါက ထိုသူ၏လုပ်ငန်းများ ထိန်းသိမ်းထားသည်။ Draft များကို ထွက်ရန် အချိန်တွင် ရှင်းလင်းပစ်သည်။

## AI စာတမ်းရိုက်ခြင်း

**စက်ပိုင်းတွင်းစာတမ်းရိုက်ခြင်း** — ခေါ်ဆိုမှုများကို စေတနာ့ဝန်ထမ်း၏ Browser တွင်းတွင် လုံးဝအလုပ်လုပ်သော AI ဖြင့် စာတမ်းရိုက်ထားသည်။ အသံသည် စက်ပိုင်းမှ ဘယ်သောအခါမျှ မထွက်ပါ။ ကုဗ္ဌအကာအကြယ်ထည့်ထားသော စာတမ်းရိုက်ချက်သာ သိမ်းဆည်းထားသည်။

**Admin နှင့် စေတနာ့ဝန်ထမ်း ထိန်းချုပ်မှုများ** — Admin များသည် စာတမ်းရိုက်ခြင်းကို ကမ္ဘာလုံးဆိုင်ရာ ဖွင့်ရန် သို့မဟုတ် ပိတ်ရန် လုပ်နိုင်သည်။ စေတနာ့ဝန်ထမ်းများသည် သီးခြားအဖြစ် ချန်လှပ်ခွင့်ပြုချက်မရှိဘဲ လုပ်နိုင်သည်။ နှစ်ခုလုံးသည် လွတ်လပ်သည့် Switch များဖြစ်သည်။

**ကုဗ္ဌအကာအကြယ်ထည့်ထားသော စာတမ်းရိုက်ချက်များ** — စာတမ်းရိုက်ချက်များသည် မှတ်စုများနှင့် တူညီသော ECIES ကုဗ္ဌအကာအကြယ်ကို အသုံးပြုသည်။ သိမ်းဆည်းထားသော စာတမ်းရိုက်ချက်သည် Ciphertext သာလျှင် ဖြစ်သည်။

## Spam လျှော့ချခြင်း

**အသံ CAPTCHA** — ရွေးချယ်နိုင်သော အသံ Bot ခွဲခြားခြင်း။ ခေါ်ဆိုသူသည် ကျပန်း 4 လုံးစာရေနံပါတ်ကို နားထောင်ရပြီး keypad တွင် ထည့်သွင်းရမည်။ အလိုအလျောက် ခေါ်ဆိုမှုကို တားဆီးပြီး တကယ်ခေါ်ဆိုသူများအတွက် လွယ်ကူမှုရှိစေသည်။

**Rate Limiting** — ဖုန်းနံပါတ်တစ်ခုချင်းစီအလိုက် Database တွင် တည်မြဲသော Sliding-Window Rate Limiting။ ပြင်ဆင်နိုင်သော Threshold များသည် Reboot ပြီးနောက်လည်း ကျန်ရှိသည်။

**Real-Time ပိတ်ပင်စာရင်းများ** — Admin များသည် ဖုန်းနံပါတ် ပိတ်ပင်စာရင်းများကို တစ်ခုချင်းစီ ထည့်သွင်းခြင်း သို့မဟုတ် အုပ်စုလိုက် ထည့်သွင်းခြင်းဖြင့် စီမံနိုင်သည်။ ပိတ်ပင်ခြင်းများသည် ချက်ချင်း ထိရောက်သည်။ ပိတ်ပင်ခံထားရသူများ ပယ်ချမှု သတင်းစကားကို နားထောင်ရသည်။

**စိတ်ကြိုက် IVR Prompts များ** — ပံ့ပိုးထားသော ဘာသာစကားတိုင်းအတွက် စိတ်ကြိုက် အသံ Prompts များကို မှတ်တမ်းတင်နိုင်သည်။ စနစ်သည် IVR လမ်းညွှန်အတွက် သင့်မှတ်တမ်းကို အသုံးပြုပြီး မှတ်တမ်းမရှိလျှင် Text-to-Speech သို့ ပြန်သွားမည်။

## မျိုးစုံချန်နယ်မှ သတင်းပို့ခြင်း

**SMS** — Twilio, SignalWire, Vonage သို့မဟုတ် Plivo မှ တဆင့် ဝင်ရောက်/ထွက်ခွာသော SMS သတင်းပို့ခြင်း။ ပြင်ဆင်နိုင်သော ကြိုဆိုမှု သတင်းစကားများဖြင့် အလိုအလျောက် ပြန်ကြားခြင်း။ သတင်းများသည် Threaded Conversation အမြင်သို့ စီးဆင်းကြသည်။

**WhatsApp Business** — Meta Cloud API (Graph API v21.0) မှ တဆင့် ချိတ်ဆက်ထားသည်။ 24-နာရီ စာတိုပို့သည့်ရက်တွင်း စကားပြောဆိုမှုများစတင်ရန် Template Message ပံ့ပိုးမှု။ ပုံများ၊ စာရွက်စာတမ်းများ နှင့် အသံများအတွက် Media Message ပံ့ပိုးမှု။

**Signal** — မိမိကိုယ်တိုင် Host လုပ်ထားသော signal-cli-rest-api Bridge မှ တဆင့် မှတ်တမ်းမှတ်ရာ အထူးအလေးထားသော သတင်းပို့ခြင်း။ Graceful Degradation ဖြင့် ကျန်းမာရေးစောင့်ကြည့်ခြင်း။ စက်ပိုင်းတွင်း Whisper AI မှ တဆင့် အသံသတင်းစာတမ်းရိုက်ခြင်း။

**Threaded စကားပြောဆိုမှုများ** — သတင်းပို့သည့်ချန်နယ်အားလုံးကို တစ်စုတစ်စည်းတည်း Conversation အမြင်သို့ စီးဆင်းကြသည်။ အချိန်မှတ်ပုံတူများနှင့် ဦးတည်ရာညွှန်းကိန်းများပါသော Message Bubbles။ Real-Time အသစ်များထွက်ခြင်း။ သတင်းအားလုံးသည် သင့် Server သို့ ရောက်သည့်အခါ ချက်ချင်း ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။ Server သည် Ciphertext သာလျှင် သိမ်းဆည်းထားသည်။

## ကုဗ္ဌအကာအကြယ်ထည့်ထားသော အစီရင်ခံချက်များ

**အစီရင်ခံပေးသူရ_throw** — အကြံပြုချက် သို့မဟုတ် အစီရင်ခံချက်များ တင်ပြသူများအတွက် သီးခြား ရ_throwဖြစ်သည်။ အစီရင်ခံပေးသူများသည် အစီရင်ခံချက်များနှင့် အကူအညီများသာ ပါသော ရိုးရှင်းသည့် Interface ကိုသာ မြင်ရသည်။ ရ_throw ရွေးချယ်ခွင့်ပါသော စေတနာ့ဝန်ထမ်းနှင့် တူညီသော လမ်းကြောင်းအတိုင်း ဖိတ်ခေါ်ထားသည်။

**ကုဗ္ဌအကာအကြယ်ထည့်ထားသော တင်ပြချက်များ** — အစီရင်ခံချက် Body သည် Browser မှ မထွက်ခင် ECIES ဖြင့် ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။ ရှင်းလင်းသော ခေါင်းစဉ်များသည် အရေးပေါ်ခွဲခြားသတ်မှတ်ရန်၊ ကုဗ္ဌအကာအကြယ်ထည့်ထားသော အကြောင်းအရာများသည် ကိုယ်ရေးကိုယ်တာအတွက် ဖြစ်သည်။ File Attachments များကို ခွဲခြားပြီး ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။

**အစီရင်ခံချက် လုပ်ငန်းလည်ပတ်မှု** — အစီရင်ခံချက်များကို အစီအစဉ်ထဲထားရန် Categories များ။ အခြေအနေများကို ခြေရာခြင်း (ဖွင့်ထား၊ လက်ခံထား၊ ပြီးစီး)။ Admin များသည် အစီရင်ခံချက်များကို လက်ခံပြီး Threaded၊ ကုဗ္ဌအကာအကြယ်ထည့်ထားသော အဖြေများဖြင့် တုံ့ပြန်နိုင်သည်။

## ဆက်သွယ်ရန်စာရင်း

**ကုဗ္ဌအကာအကြယ်ထည့်ထားသော ဆက်သွယ်ရန်မှတ်တမ်းများ** — End-to-End ကုဗ္ဌအကာအကြယ်ဖြင့် ဆက်သွယ်ရန်အချက်အလက်များကို သိမ်းဆည်းထားသည်။ အမည်၊ ဖုန်းနံပါတ်၊ အီးမေးလ် နှင့် မှတ်စုများကို Browser မှ မထွက်ခင် ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။

**ဆက်ဆံရေးခြေရာခြင်း** — ဆက်သွယ်သူများကို တစ်ဦးနှင့် တစ်ဦး နှင့် ခေါ်ဆိုမှုများ၊ စကားပြောဆိုမှုများနှင့် အစီရင်ခံချက်များနှင့် ဆက်စပ်ပေးထားသည်။ သင်ကူညီနေသော လူများအပေါ် ပုံရိပ်အပြည့်ကို တည်ဆောက်ပါ။

**အလိုအလျောက်ဆက်စပ်ခြင်း** — ဝင်ရောက်လာသော ခေါ်ဆိုမှုများနှင့် သတင်းများကို ဖုန်းနံပါတ်ညီချိန်ဖြင့် သိရှိထားသော ဆက်သွယ်သူများနှင့် အလိုအလျောက်ဆက်စပ်ပေးသည်။

**အဖွဲ့အစည်းအခြေခံသော ဝင်ရောက်ခွင့်** — မည်သည့်အဖွဲ့အစည်းဝင်များက မည်သည့်ဆက်သွယ်သူများကို မြင်နိုင်ကြကို ထိန်းချုပ်ပါ။ ခွင့်ပြုချက်များသည် အသေးစိတ်နှင့် ပြေကျင်းနိုင်သော အရာများဖြစ်သည်။

**Tags နှင့် လက်ခံသွင်းခြင်း** — Tags များအသုံးပြုပြီး ဆက်သွယ်သူများကို အစီအစဉ်ထဲထားပါ။ လက်ခံသွင်းခြင်း လုပ်ငန်းလည်ပတ်မှုများသည် ဆက်သွယ်သူအသစ်များကို ပြန်လည်သုံးသပ်ရန် လမ်းညွှန်ပေးသည်။

**အစုလိုက်သွင်းကုန်/ထုတ်ကုန်** — CSV သို့မဟုတ် JSON မှ ဆက်သွယ်သူများကို သွင်းကုန်လုပ်ပါ။ ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Backup များကို ထုတ်ကုန်လုပ်ပါ။ လုပ်ငန်းစဉ်အားလုံးသည် သင့်Browser တွင်းသာ ပြုလုပ်သည်။

## ပြေကျင်းနိုင်သော ခွင့်ပြုချက်များ

**စိတ်ကြိုက် ရ_throwများ** — လိုအပ်သော ခွင့်ပြုချက်များတိတိကျကျပါဝင်သော သင့်ကိုယ်ပိုင် ရ_throwများကို သတ်မှတ်ပါ။ Built-in Templates (Admin, စေတနာ့ဝန်ထမ်း၊ အစီရင်ခံပေးသူ) မှ စတင်ပါ သို့မဟုတ် အခြေခံမှ စတင်တည်ဆောက်ပါ။

**အသေးစိတ်ခွင့်ပြုချက်များ** — လက္ခဏာ 17 ဧရိယာတွင် တစ်ဦးချင်း ခွင့်ပြုချက် 90 ကျော်ထက် မနည်း။ မည်သူက ကြည့်ရှု၊ ဖန်တီး၊ ပြင် ဆင် နှင့် ဖျက်နိုင်သည်ကို အသေးစိတ်အဆင့်တွင် ထိန်းချုပ်ပါ။

**အဖွဲ့အစည်းအကျဉ်းအကျုပ်** — အဖွဲ့အစည်းဝင်များကို အဖွဲ့များသို့ ခန့်ထားပါ။ ခွင့်ပြုချက်များကို သီးခြားအဖွဲ့များသို့ ကန့်သတ်နိုင်သည်၊ ထို့ကြောင့် အုပ်စုအလိုက် Data ကွဲပြားခြားနားစွာ မြင်ရသည်။

## Admin Dashboard

**Setup Wizard** — ပထမဆုံး Admin Login အချိန်တွင် အဆင့်အစဉ်လိုက်ညွှန်ကြားသော ဘာသာစကားအမျိုးမျိုးဖြင့် Setup။ မည်သည့်ချန်နယ်များကို ဖွင့်ရမည် (အသံ၊ SMS၊ WhatsApp၊ Signal၊ အစီရင်ခံချက်များ) ရွေးချယ်ပြီး Provider များကို ပြင်ဆင်ပြီး သင့်အပူပိုင်းလိုင်းအမည်ကို သတ်မှတ်ပါ။

**Getting Started Checklist** — Setup တိုးတက်မှုကို ခြေရာခံပေးသော Dashboard Widget။ ချန်နယ်တည်ဆောက်မှု၊ စေတနာ့ဝန်ထမ်း Onboarding၊ Shift ဖန်တီးခြင်း။

**Real-Time စောင့်ကြည့်ခြင်း** — အသက်ဝင်နေသော ခေါ်ဆိုမှုများ၊ စီတန်းတွင် စောင့်ဆိုင်းနေသူများ၊ စကားပြောဆိုမှုများနှင့် စေတနာ့ဝန်ထမ်း အခြေအနေများကို Real-Time တွင် ကြည့်ရှုပါ။ မှတ်တမ်းများ ချက်ချင်း Update ဖြစ်သည်။

**အသုံးပြုသူ စီမံခန့်ခွဲမှု** — လုံခြုံသော Link များမှတဆင့် အဖွဲ့အသစ်ဝင်များကို ဖိတ်ခေါ်ပါ။ ၎င်းတို့သည် ကိုယ်ပိုင် အကောင့်နှင့် ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Keys များကို ဖန်တီးကြသည်။ ရ_throwများ၊ ခွင့်ပြုချက်များနှင့် အဖွဲ့ခန့်ထားမှုများကို စီမံခန့်ခွဲပါ။

**Audit Logging** — ခေါ်ဆိုမှုတိုင်း ဖြေကြားခြင်း၊ မှတ်စုတိုင်း ဖန်တီးခြင်း၊ သတင်းတိုင်း ပို့ခြင်း၊ အစီရင်ခံချက်တိုင်း တင်ပြခြင်း၊ Setting တိုင်း ပြောင်းလဲခြင်း နှင့် Admin လုပ်ဆောင်ချက်တိုင်း မှတ်တမ်းတင်ထားသည်။ Admin အတွက် Pagination Viewer။

**ခေါ်ဆိုမှု မှတ်တမ်း** — ရက်စွဲအပိုင်းအခြား၊ ဖုန်းနံပါတ် ရှာဖွေခြင်းနှင့် စေတနာ့ဝန်ထမ်း ခန့်ထားခြင်းဖြင့် ရှာဖွေနိုင်ပြီး Filter လုပ်နိုင်သော ခေါ်ဆိုမှု မှတ်တမ်း။ GDPR နှင့်ညီသော Data ထုတ်ပေးခြင်း။

**အက်ပ်အတွင်း ကူညီခြင်း** — အမြဲမေးလေ့ရှိသော မေးခွန်းများ၊ ရ_throwသီးခြားလမ်းညွှန်များ၊ Keyboard Shortcuts နှင့် လုံခြုံရေး အမြန်ညွှန်းကတ်များ။ Sidebar နှင့် Command Palette မှတဆင့် ဝင်ရောက်နိုင်သည်။

## စေတနာ့ဝန်ထမ်း အတွေ့အကြုံ

**Command Palette** — Ctrl+K (သို့မဟုတ် Mac မှာ Cmd+K) နှိပ်ပြီး ချက်ချင်း Navigation၊ ရှာဖွေခြင်း၊ မှတ်စု အမြန်ဖန်တီးခြင်း နှင့် Theme ပြောင်းခြင်းများကို ဝင်ရောက်နိုင်သည်။ Admin-only Commands များကို ရ_throwအလိုက် Filter လုပ်ထားသည်။

**Real-Time အသိပေးချက်များ** — ဝင်ရောက်လာသော ခေါ်ဆိုမှုများသည် Browser Ringtone၊ Push Notification နှင့် မှိတ်နေသော Tab Title ကို Trigger လုပ်သည်။ Setting တွင် အသိပေးချက် အမျိုးအစားတိုင်းကို လွတ်လပ်စွာ On/Off လုပ်နိုင်သည်။

**စေတနာ့ဝန်ထမ်း တက်ရောက်မှု** — Admin များသည် Online၊ Offline နှင့် အနားယူမှု ရေတွက်ချက်မှုများကို Real-Time တွင် မြင်ရသည်။ စေတနာ့ဝန်ထမ်းများသည် Sidebar တွင် အနားယူ Switch ကို Toggle လုပ်ပြီး ၎င်းတို့၏ Shift မထွက်ဘဲ ဝင်လာသော ခေါ်ဆိုမှုများကို ယာယီရပ်တန့်ထားနိုင်သည်။

**Keyboard Shortcuts** — ရရှိနိုင်သော Shortcuts အားလုံးကို ကြည့်ရှုရန် ? နှိပ်ပါ။ စာမျက်နှာများသို့ သွားရောက်၊ Command Palette ကို ဖွင့်၍ ပုံမှန်လုပ်ဆောင်ချက်များကို Mouse မထိဘဲ ပြုလုပ်နိုင်သည်။

**မှတ်စု Draft Auto-Save** — မှတ်စုများသည် Browser တွင် ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Draft အဖြစ် အလိုအလျောက်သိမ်းဆည်းထားသည်။ စာမျက်နှာ ပြန်လည်တင်ပါက သို့မဟုတ် စေတနာ့ဝန်ထမ်း ထွက်ခွာပါက ထိုသူ၏လုပ်ငန်းများ ထိန်းသိမ်းထားသည်။ Draft များကို Logout အချိန်တွင် localStorage မှ ရှင်းလင်းပစ်သည်။

**ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Data ထုတ်ပေးခြင်း** — မှတ်စုများကို GDPR နှင့်ညီသော ကုဗ္ဌအကာအကြယ်ထည့်ထားသော ဖိုင် (.enc) အဖြစ် ထုတ်ပေးနိုင်သည်။ သင့်က Multi-Factor Encryption Key ဖြင့် ကာကွယ်ထားသည်။ မူလရေးသားသူသာ ထုတ်ပေးထားသည်ကို ဖြည်ဖတ်နိုင်သည်။

**မှောင်မိုက်/အလင်းရောင် Theme များ** — Dark Mode၊ Light Mode သို့မဟုတ် System Theme အလိုက် ပြောင်းလဲခြင်း။ Session တိုင်းအလိုက် ဦးစားပေးချက် သိမ်းဆည်းထားသည်။

## ဘာသာစကားများစွာ နှင့် မိုဘိုင်းဖုန်း

**12+ ဘာသာစကား** — UI ဘာသာစကားပြန်ဆိုချက်များ ပြီးပြည့်စုံစွာ။ အင်္ဂလိပ်၊ စပိန်၊ တရုတ်၊ တာဂလော့ဂ်၊ ဗီယက်နမ်၊ အာရဗီ၊ ပြင်သစ်၊ ဟေတီကရီအိုလ်၊ ကိုရီးယား၊ ရုရှား၊ ဟင်ဒီ၊ ပေါ်တူဂီ နှင့် ဂျာမန်။ အာရဗီအတွက် RTL ပံ့ပိုးမှု။

**Progressive Web App** — Browser မှတဆင့် မည်သည့်စက်ပိုင်းပေါ်မဆိုထည့်သွင်းနိုင်သည်။ Service Worker သည် Offline ဖြင့်စတင်နိုင်ရန် App Shell ကို Cache လုပ်ထားသည်။ ဝင်ရောက်လာသော ခေါ်ဆိုမှုများအတွက် Push Notifications များ။

**Mobile-First Design** — ဖုန်းများနှင့် Tablet များအတွက် ရေးသားထားသော Responsive Layout။ အပေါ်အောက် လုပ်နိုင်သော Sidebar၊ Touch-friendly Controls နှင့် အညီအမျှလိုက်ဖက် Layout များ။

## အထောက်အထားစစ်ဆေးခြင်း နှင့် Key စီမံခန့်ခွဲမှု

**Multi-Factor Key Protection** — သင့်ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Key သည် လွတ်လပ်သော အကျိုးသက်ရောက်မှု 3 ခုပထမ ထိန်းသိမ်းထားသည်။ သင်ရွေးချယ်ထားသော PIN၊ သင်၏ Identity Provider အကောင့် နှင့် ရွေးချယ်နိုင်သော Hardware Security Key။ တစ်ခုသာ ထိခိုက်ခြင်းဖြင့် လုံလောက်မည်မဟုတ်။

**Identity Provider ချိတ်ဆက်မှု** — မိမိကိုယ်တိုင် Host လုပ်ထားသော မှတ်ပုံတင်စီမံခန့်ခွဲမှု (သင်၏ထိန်းချုပ်မှုအောက်)။ ဖိတ်ခေါ်မှုအခြေခံ Onboarding — လျှို့ဝှက် Keys မျှဝေရန် မလိုအပ်။ Remote Session Cancellation — မည်သည့်နေရာမှမဆို ထိခိုက်နေသော စက်ပိုင်းကို Lock လုပ်နိုင်သည်။

**အလိုအလျောက် Session စီမံခန့်ခွဲမှု** — Session များသည် Background တွင် ငြိမ်သက်စွာ Refresh ဖြစ်သည်။ တိတ်ဆိတ်မှု Auto-Lock သည် ကိုယ်စားလှယ်မထားသော စက်ပိုင်းများကို ကာကွယ်ပေးသည်။ သင့်ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Key သည် သီးခြားလုပ်ငန်းစဉ်တွင် ရှိပြီး စာမျက်နှာမှ ဘယ်သောအခါမျှ ဝင်ရောက်ခွင့်မရှိ။

**စက်ပိုင်းချိတ်ဆက်မှု** — စက်ပိုင်းအသစ်များကို လုံခြုံစွာ Setup လုပ်ပါ။ QR Code ကို Scan လုပ်ပါ သို့မဟုတ် တိုတိုသော Provisioning Code ကို ထည့်သွင်းပါ။ ယာယီ Key လဲလှယ်ခြင်း အသုံးပြုသည် — လွှဲပြောင်းသည့်အခါ သင့်လျှို့ဝှက် Key ဘယ်သောအခါမျှ မပေါ်ပေါက်ပါ။

**Recovery Keys** — Onboarding အတွင်း အရေးပေါ်အခြေအနေများအတွက် Recovery Key တစ်ခု ရရှိမည်ဖြစ်သည်။ ဆက်လက်ပြုလုပ်ခွင့်ရရန် မဖြစ်မနေ ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Backup လိုအပ်သည်။

**Hardware Security Keys** — Phishing-resistant Login အတွက် ရွေးချယ်နိုင်သော Passkey ပံ့ပိုးမှု။ Hardware Key သို့မဟုတ် Biometric ကို မှတ်ပုံတင်ပြီး အထောက်အထားများထည့်သွင်းစရာမလိုဘဲ Login ဝင်နိုင်သည်။

**အသီးသီးသော မှတ်စု Forward Secrecy** — မှတ်စုတစ်ခုစီကို ထူးခြားသော ကျပန်းသောလျှို့ဝှက် Key ဖြင့် ကုဗ္ဌအကာအကြယ်ထည့်ထားပြီး ထို Key ကို ခွင့်ပြုထားသော ဖတ်ရှုသူတိုင်း အတွက် ECIES ဖြင့် Wrapped လုပ်ထားသည်။ Identity Key ထိခိုက်ခြင်းသည် ယခင်မှတ်စုများကို မဖော်ပြပါ။
