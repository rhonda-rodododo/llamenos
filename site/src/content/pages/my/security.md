## သင်၏ Hosting Provider အပေါ် Subpoena ရှိလျှင်

| သူတို့ပေးနိုင်သည် | သူတို့မပေးနိုင်ပါ |
|----------------|---------------|
| ခေါ်ဆိုမှု/သတင်းပို့မှု Metadata (အချိန်၊ ကြာချိန်) | မှတ်စုအကြောင်းအရာ၊ စာတမ်းရိုက်ချက်များ၊ အစီရင်ခံချက် အကြောင်းအရာများ |
| ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Database Blobs | စေတနာ့ဝန်ထမ်း အမည်များ (End-to-End ကုဗ္ဌအကာအကြယ်ထည့်) |
| မည်သည့်စေတနာ့ဝန်ထမ်း အကောင့်များ မည်သည့်အချိန်တွင် လှုပ်ရှားခဲ့သည် | ဆက်သွယ်ရန်စာရင်း မှတ်တမ်းများ (End-to-End ကုဗ္ဌအကာအကြယ်ထည့်) |
| | သတင်းပို့မှု အကြောင်းအရာများ (ရောက်သောအခါ ကုဗ္ဌအကာအကြယ်ထည့်၊ Ciphertext အဖြစ် သိမ်းဆည်း) |
| | Decryption Keys (သင်၏ PIN၊ အထောက်အထားပြစ် Provider အကောင့် နှင့် ရွေးချယ်နိုင်သော Hardware Security Key ဖြင့် ကာကွယ်ထား) |
| | မှတ်စုတစ်ခုချင်း Encryption Keys (ယာယီ — Wrap လုပ်ပြီးနောက် ဖျက်ပစ်) |
| | ဖုန်းနံပါတ် Hash များကို နောက်ပြန်လှန်ရန် သင်၏ HMAC လျှို့ဝှက် |

**Server သည် ဖတ်ရှု၍မရသော Data များကို သိမ်းဆည်းထားသည်။** Metadata (ဘယ်အချိန်၊ ဘယ်လောက်၊ မည်သည့်အကောင့်များ) များကို မြင်ရသည်။ အကြောင်းအရာ (ဘယ်လိုပြောခဲ့သည်၊ ဘယ်လိုရေးခဲ့သည်၊ သင်၏ဆက်သွယ်သူများကို မြင်ရသည်) များကို မမြင်ရပါ။

## လက္ခဏာအလိုက်

သင်၏ကိုယ်ရေးကိုယ်တာအချက်အလက် ထိပ်တိုက်တွေ့မှူသည် သင်ဖွင့်ထားသော ချန်နယ်များအပေါ် မူတည်သည်။

### အသံခေါ်ဆိုမှုများ

| သင်အသုံးပြုသော... | တတိယပါတီ ဝင်ရောက်နိုင်ချေ | Server ဝင်ရောက်နိုင်ချေ | End-to-End ကုဗ္ဌအကာအကြယ်ထည့်ထားသော အကြောင်းအရာ |
|------------------|------------------------|---------------------|----------------------------------------|
| Twilio/SignalWire/Vonage/Plivo | ခေါ်ဆိုမှုအသံ (တိုက်ရိုက်)၊ ခေါ်ဆိုမှု မှတ်တမ်းများ | ခေါ်ဆိုမှု Metadata | မှတ်စုများ၊ စာတမ်းရိုက်ချက်များ |
| မိမိကိုယ်တိုင် Host လုပ်ထားသော Asterisk | မည်သည့်အရာမျှမရှိ (သင်၏ထိန်းချုပ်မှုအောက်) | ခေါ်ဆိုမှု Metadata | မှတ်စုများ၊ စာတမ်းရိုက်ချက်များ |
| Browser-to-Browser (WebRTC) | မည်သည့်အရာမျှမရှိ | ခေါ်ဆိုမှု Metadata | မှတ်စုများ၊ စာတမ်းရိုက်ချက်များ |

**တယ်လီဖုန်းပေး Provider Subpoena** — ၎င်းတို့တွင် ခေါ်ဆိုမှု အသေးစိတ်မှတ်တမ်းများ (အချိန်၊ ဖုန်းနံပါတ်၊ ကြာချိန်) ရှိသည်။ ခေါ်ဆိုမှု မှတ်စုများနှင့် စာတမ်းရိုက်ချက်များကို မရှိပါ။ အသံသွင်းခြင်းကို ပုံမှန်အတိုင်းပိတ်ထားသည်။

**စာတမ်းရိုက်ခြင်း** — စာတမ်းရိုက်ခြင်းသည် သင့်သော Browser တွင် On-Device AI ကို အသုံးပြုပြီး လုံးဝပြုလုပ်သည်။ အသံသည် သင့်Device မှ ဘယ်သောအခါမျှ မထွက်ပါ။ ကုဗ္ဌအကာအကြယ်ထည့်ထားသော စာတမ်းရိုက်ချက်သာ သိမ်းဆည်းထားသည်။

### စာသားသတင်းပို့မှု

| ချန်နယ် | Provider ဝင်ရောက်မှု | Server သိမ်းဆည်းမှု | မှတ်ချက် |
|--------|-------------------|------------------|--------|
| SMS | သင်၏တယ်လီဖုန်းပေးက အကုန်လုံးကို ဖတ်ရှုသည် | **ကုဗ္ဌအကာအကြယ်ထည့်** | Provider သည် မူရင်းသတင်းစကားများကို ထားရှိသည် |
| WhatsApp | Meta က အကုန်လုံးကို ဖတ်ရှုသည် | **ကုဗ္ဌအကာအကြယ်ထည့်** | Provider သည် မူရင်းသတင်းစကားများကို ထားရှိသည် |
| Signal | Signal ကွန်ယက်သည် End-to-End ကုဗ္ဌအကာအကြယ်ထည့်ထားသော်လည်း Bridge သည် ရောက်သောအခါ Decrypt လုပ်သည် | **ကုဗ္ဌအကာအကြယ်ထည့်** | SMS ထက်ကောင်းသော်လည်း Zero-Knowledge မဟုတ် |

**သတင်းစကားများသည် သင့်Server သို့ ရောက်သောအခါ ချက်ချင်း ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။** Server သည် Ciphertext သာလျှင် သိမ်းဆည်းထားသည်။ သင်၏တယ်လီဖုန်းပေး သို့မဟုတ် သတင်းပို့Provider သည် မူရင်းသတင်းစကားကို ဆက်လက်ထားရှိနိုင်သည် — ၎င်းသည် ထိုပလက်ဖောင်းများ၏ ကန့်သတ်ချက်ဖြစ်ပြီး ငါတို့ပြောင်းလဲ၍မရသောအရာဖြစ်သည်။

**သတင်းပို့Provider Subpoena** — SMS Provider များတွင် သတင်းစကားများ၏ အကြောင်းအရာလုံးဝရှိသည်။ Meta တွင် WhatsApp အကြောင်းအရာရှိသည်။ Signal သတင်းစကားများသည် Bridge အထိ End-to-End ကုဗ္ဌအကာအကြယ်ထည့်ထားသော်လည်း Bridge (သင်၏Server တွင် လုပ်ဆောင်နေသော) သည် သိမ်းဆည်းရန် Re-encrypt မလုပ်ခင် Decrypt လုပ်သည်။ မည်သည့်အခြေအနေမျိုးဖြစ်ဖြစ် **သင်၏Server တွင် Ciphertext သာလျှင်ရှိသည်** — Hosting Provider သည် သတင်းစကားအကြောင်းအရာကို ဖတ်ရှု၍မရပါ။

### မှတ်စုများ၊ စာတမ်းရိုက်ချက်များနှင့် အစီရင်ခံချက်များ

စေတနာ့ဝန်ထမ်းများရေးသားထားသော အကြောင်းအရာအားလုံးသည် End-to-End ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။

- မှတ်စုတစ်ခုစီတွင် ထူးခြားသော ကျပန်းသောလျှို့ဝှက် Key ဖြင့် ကုဗ္ဌအကာအကြယ်ထည့်ထားသည် (Forward Secrecy — မှတ်စုတစ်ခု ထိခိုက်ခြင်းဖြင့် ကျန်မှုများကို မထိခိုက်စေ)
- Keys များကို စေတနာ့ဝန်ထမ်းနှင့် Admin တိုင်းအတွက် ခွဲခြားပြီး Wrap လုပ်ထားသည်
- Server သည် Ciphertext သာလျှင် သိမ်းဆည်းထားသည်
- Decryption သည် Browser တွင်းတွင် ပြုလုပ်သည်
- **စိတ်ကြိုက် Fields များ၊ အစီရင်ခံချက် အကြောင်းအရာများနှင့် File Attachments များအားလုံး ခွဲခြားပြီး ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်**

**Device သိမ်းဆည်းခံရခြင်း** — သင်၏PIN နှင့် သင်၏အထောက်အထားပြစ် Provider အကောင့်သို့ ဝင်ရောက်ခွင့်မရှိပါက တိုက်ခိုက်သူများသည် Mathematical ရှုထောင့်မှ မရေတွက်နိုင်သော ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Blob သာလျှင် ရရှိမည်။ သင်လည်း Hardware Security Key ကို အသုံးပြုလျှင် **လွတ်လပ်သော အကျိုးသက်ရောက်မှု 3 ခု** သည် သင်၏Data များကို ကာကွယ်ပေးမည်။

## စေတနာ့ဝန်ထမ်း ဖုန်းနံပါတ် ကိုယ်ရေးကိုယ်တာအချက်အလက်

စေတနာ့ဝန်ထမ်းများသည် ၎င်းတို့၏ကိုယ်ပိုင်ဖုန်းများပေါ်တွင် ခေါ်ဆိုမှုများကို ဖြေကြားသောအခါ ၎င်းတို့၏နံပါတ်များသည် သင်၏တယ်လီဖုန်းပေး Provider အား ထင်ရှားစေသည်။

| အခြေအနေ | ဖုန်းနံပါတ်အား မြင်နိုင်သူ |
|---------|------------------------|
| စေတနာ့ဝန်ထမ်း ဖုန်းသို့ PSTN ခေါ်ဆိုမှု | တယ်လီဖုန်းပေး Provider၊ ဆယ်လူလာ Carrier |
| Browser-to-Browser (WebRTC) | မည်သူမျှမရှိ (အသံသည် Browser တွင်သာ ရှိသည်) |
| မိမိကိုယ်တိုင် Host လုပ်ထားသော Asterisk + SIP ဖုန်း | သင်၏Asterisk Server သီးခြား |

**စေတနာ့ဝန်ထမ်း ဖုန်းနံပါတ်များကို ကာကွယ်ရန်** — Browser-based Calling (WebRTC) ကို အသုံးပြုပါ သို့မဟုတ် မိမိကိုယ်တိုင် Host လုပ်ထားသော Asterisk သို့ ချိတ်ဆက်ထားသော SIP ဖုန်းများကို ပေးပါ။

## မကြာသေးခင်က မိတ်ဆက်ပြသခြင်း

ယခု တိုးတက်မှုများကို လက်တွေ့အသုံးချနေပြီ။

| လက္ခဏာ | ကိုယ်ရေးကိုယ်တာအချက်အလက် အကျိုးကျေးဇူး |
|--------|-------------------------------------|
| ကုဗ္ဌအကာအကြယ်ထည့်ထားသော သတင်းစကားသိမ်းဆည်းခြင်း | SMS၊ WhatsApp နှင့် Signal သတင်းစကားများကို သင်၏Server တွင် Ciphertext အဖြစ် သိမ်းဆည်းထားသည် |
| On-Device စာတမ်းရိုက်ခြင်း | အသံသည် သင်၏Browser မှ ဘယ်သောအခါမျှ မထွက် — လုံးဝ သင့်Device တွင် ပြုလုပ်သည် |
| Multi-Factor Key Protection | သင်၏Encryption Keys များကို သင်၏PIN၊ အထောက်အထားပြစ် Provider နှင့် ရွေးချယ်နိုင်သော Hardware Security Key ဖြင့် ကာကွယ်ထားသည် |
| Hardware Security Keys | ရုပ်ဝတ္ထု Keys များသည် ဝေးလံခေါင်သီးမှု တစ်ခုဖြင့် တတိယအကျိုးသက်ရောက်မှုကို ထည့်သွင်းပေးသည် |
| Reproducible Builds | Deploy လုပ်ထားသော Code သည် အများပြည်သူသိရှိသော ရင်းမြစ်နှင့် ကိုက်ညီသည် ဟု အတည်ပြုပါ |
| ကုဗ္ဌအကာအကြယ်ထည့်ထားသော ဆက်သွယ်ရန်စာရင်း | ဆက်သွယ်ရန်မှတ်တမ်းများ၊ ဆက်ဆံရေးများနှင့် မှတ်စုများ End-to-End ကုဗ္ဌအကာအကြယ်ထည့်ထားသည် |
