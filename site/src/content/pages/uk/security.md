## Якщо вашого хостинг-провайдера викликають до суду

| Вони МОЖУТЬ надати | Вони НЕ МОЖУТЬ надати |
|------------------|---------------------|
| Метадані дзвінків/повідомлень (час, тривалість) | Вміст нотаток, транскрипції, тіла повідомлень |
| Зашифровані blobs бази даних | Імена волонтерів (наскрізне шифрування) |
| Які облікові записи волонтерів були активні в той час | Записи контактного довідника (наскрізне шифрування) |
| | Вміст повідомлень (шифрується після надходження, зберігається як шифротекст) |
| | Ключі дешифрування (захищені вашим PIN-кодом, обліковим записом постачальника ідентифікації та опціональним апаратним ключем безпеки) |
| | Ключі шифрування для кожної нотатки (епемерні — знищуються після обгортання) |
| | Ваш HMAC-секрет для зворотного перетворення хешів телефонів |

**Сервер зберігає дані, які не може прочитати.** Метадані (коли, як довго, які облікові записи) видно. Вміст (що було сказано, що було написано, хто ваші контакти) — ні.

## За функціями

Ваше приватне розкриття залежить від каналів, які ви ввімкнули:

### Голосові дзвінки

| Якщо ви використовуєте... | Треті сторони мають доступ | Сервер має доступ | Зміст з наскрізним шифруванням |
|---------------|-------------------------|-------------------|------------------------------|
| Twilio/SignalWire/Vonage/Plivo | Аудіо дзвінка (у реальному часі), записи дзвінків | Метадані дзвінків | Нотатки, транскрипції |
| Самостійно розгорнутий Asterisk | Нічого (ви контролюєте) | Метадані дзвінків | Нотатки, транскрипції |
| Браузер до браузера (WebRTC) | Нічого | Метадані дзвінків | Нотатки, транскрипції |

**Повістка провайдеру телефонії**: вони мають записи деталізації дзвінків (час, номери телефонів, тривалість). У них НЕМАЄ нотаток або транскрипцій. Запис дзвінків вимкнено за замовчуванням.

**Транскрипція**: транскрипція відбувається повністю у вашому браузері за допомогою локального ШІ. **Аудіо ніколи не покидає ваш пристрій.** Зберігається лише зашифрована транскрипція.

### Текстові повідомлення

| Канал | Доступ провайдера | Зберігання на сервері | Примітки |
|---------|-----------------|----------------|-------|
| SMS | Ваш телефонний провайдер читає всі повідомлення | **Зашифровано** | Провайдер зберігає оригінальні повідомлення |
| WhatsApp | Meta читає всі повідомлення | **Зашифровано** | Провайдер зберігає оригінальні повідомлення |
| Signal | Мережа Signal має наскрізне шифрування, але міст розшифровує після надходження | **Зашифровано** | Краще за SMS, але не zero-knowledge |

**Повідомлення шифруються миттєво після надходження на ваш сервер.** Сервер зберігає лише шифротекст. Ваш телефонний або месенджер-провайдер може мати оригінальне повідомлення — це обмеження цих платформ, а не те, що ми можемо змінити.

**Повістка месенджер-провайдеру**: SMS-провайдери мають повний вміст повідомлень. Meta має вміст WhatsApp. Повідомлення Signal мають наскрізне шифрування до мосту, але міст (який працює на вашому сервері) розшифровує їх перед повторним шифруванням для зберігання. У всіх випадках **на вашому сервері лише шифротекст** — хостинг-провайдер не може прочитати вміст повідомлень.

### Нотатки, транскрипції та повідомлення

Увесь вміст, написаний волонтерами, має наскрізне шифрування:

- Кожна нотатка використовує **унікальний випадковий ключ** (пряма секретність — компрометація однієї нотатки не компрометує інші)
- Ключі обгортаються окремо для волонтера та кожного адміністратора
- Сервер зберігає лише шифротекст
- Дешифрування відбувається в браузері
- **Користувацькі поля, вміст повідомлень і вкладені файли шифруються окремо**

**Вилучення пристрою**: без вашого PIN-коду **ТА** доступу до облікового запису постачальника ідентифікації зловмисники отримають зашифрований blob, який обчислювально неможливо розшифрувати. Якщо ви також використовуєте апаратний ключ безпеки, **три незалежні фактори** захищають ваші дані.

## Конфіденційність номера телефону волонтера

Коли волонтери отримують дзвінки на свої особисті телефони, їхні номери розкриваються телефонному провайдеру.

| Сценарій | Номер телефону видно |
|----------|------------------------|
| PSTN-дзвінок на телефон волонтера | Телефонному провайдеру, оператору зв’язку |
| Браузер до браузера (WebRTC) | Нікому (аудіо залишається в браузері) |
| Самостійний Asterisk + SIP-телефон | Лише вашому серверу Asterisk |

**Для захисту номерів телефонів волонтерів**: використовуйте дзвінки на основі браузера (WebRTC) або надавайте SIP-телефони, підключені до самостійного Asterisk.

## Нещодавно впроваджене

Ці покращення вже працюють:

| Функція | Перевага для конфіденційності |
|---------|-----------------|
| Зашифроване зберігання повідомлень | SMS, WhatsApp і Signal повідомлення зберігаються як шифротекст на вашому сервері |
| Транскрипція на пристрої | Аудіо ніколи не покидає ваш браузер — обробляється повністю на вашому пристрої |
| Багатофакторний захист ключа | Ваші ключі шифрування захищені вашим PIN-кодом, постачальником ідентифікації та опціональним апаратним ключем безпеки |
| Апаратні ключі безпеки | Фізичні ключі додають третій фактор, який не можна скомпрометувати віддалено |
| Відтворювані збірки | Перевірте, що розгорнутий код відповідає публічному джерелу |
| Зашифрований контактний довідник | Контактні записи, зв’язки та нотатки мають наскрізне шифрування |

## У планах

| Функція | Перевага для конфіденційності |
|---------|-----------------|
| Нативні застосунки для прийому дзвінків | Особисті номери телефонів не розкриваються |
