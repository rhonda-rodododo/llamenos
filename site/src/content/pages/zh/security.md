## 如果您的托管提供商收到传票

| 他们可以提供 | 他们无法提供 |
|-------------|-------------|
| 通话/消息元数据（时间、时长） | 笔记内容、转录文本、报告正文 |
| 加密的数据库 blob | 志愿者姓名（端到端加密） |
| 哪些志愿者账户何时活跃 | 联系人目录记录（端到端加密） |
| | 消息内容（到达时加密，以密文存储） |
| | 解密密钥（受您的 PIN、身份提供商账户和可选硬件安全密钥保护） |
| | 逐条笔记加密密钥（临时的 — 包装后销毁） |
| | 您用于反转电话哈希的 HMAC 密钥 |

**服务器存储它无法读取的数据。** 元数据（何时、多长、哪些账户）是可见的。内容（说了什么、写了什么、您的联系人是谁）不是。

## 按功能分类

您的隐私暴露取决于您启用了哪些渠道：

### 语音通话

| 如果您使用... | 第三方可以访问 | 服务器可以访问 | 端到端加密内容 |
|---------------|---------------|----------------|----------------|
| Twilio/SignalWire/Vonage/Plivo | 通话音频（实时）、通话记录 | 通话元数据 | 笔记、转录文本 |
| 自托管 Asterisk | 无（由您控制） | 通话元数据 | 笔记、转录文本 |
| 浏览器对浏览器（WebRTC） | 无 | 通话元数据 | 笔记、转录文本 |

**电话提供商传票**：他们拥有通话详单记录（时间、电话号码、时长）。他们没有通话笔记或转录文本。默认禁用录音。

**转录**：转录完全在您的浏览器中使用设备端 AI 进行。**音频永远不会离开您的设备。** 仅存储加密的转录文本。

### 短信

| 渠道 | 提供商访问权限 | 服务器存储 | 备注 |
|------|---------------|-----------|------|
| 短信 | 您的电话提供商阅读所有消息 | **加密** | 提供商保留原始消息 |
| WhatsApp | Meta 阅读所有消息 | **加密** | 提供商保留原始消息 |
| Signal | Signal 网络是端到端加密的，但桥接在到达时解密 | **加密** | 比短信好，但不是零知识 |

**消息在到达您的服务器时立即加密。** 服务器仅存储密文。您的电话或消息提供商可能仍然拥有原始消息 — 这是这些平台的限制，不是我们可以改变的。

**消息提供商传票**：短信提供商拥有完整的消息内容。Meta 拥有 WhatsApp 内容。Signal 消息到桥接是端到端加密的，但桥接（在您的服务器上运行）在重新加密存储之前将其解密。在所有情况下，**您的服务器只有密文** — 托管提供商无法阅读消息内容。

### 笔记、转录文本和报告

所有志愿者撰写的内容都是端到端加密的：

- 每条笔记使用**唯一的随机密钥**（前向保密 — compromise 一条笔记不会 compromise 其他笔记）
- 密钥分别为志愿者和每位管理员单独包装
- 服务器仅存储密文
- 解密在浏览器中进行
- **自定义字段、报告内容和文件附件都是单独加密的**

**设备扣押**：没有您的 PIN **和** 身份提供商账户的访问权限，攻击者只能获得计算上不可解密的加密 blob。如果您还使用硬件安全密钥，**三个独立因素**保护您的数据。

## 志愿者电话号码隐私

当志愿者通过个人电话接听电话时，他们的号码会暴露给您的电话提供商。

| 场景 | 电话号码对以下人员可见 |
|------|----------------------|
| PSTN 呼叫到志愿者的电话 | 电话提供商、电话运营商 |
| 浏览器对浏览器（WebRTC） | 无人（音频保留在浏览器中） |
| 自托管 Asterisk + SIP 电话 | 仅您的 Asterisk 服务器 |

**为了保护志愿者电话号码**：使用基于浏览器的通话（WebRTC）或提供连接到自托管 Asterisk 的 SIP 电话。

## 最近发布

这些改进现已上线：

| 功能 | 隐私收益 |
|------|---------|
| 加密消息存储 | 短信、WhatsApp 和 Signal 消息以密文形式存储在您的服务器上 |
| 设备端转录 | 音频永远不会离开您的浏览器 — 完全在您的设备上处理 |
| 多因素密钥保护 | 您的加密密钥受您的 PIN、身份提供商和可选硬件安全密钥保护 |
| 硬件安全密钥 | 物理密钥添加了无法远程 compromise 的第三个因素 |
| 可重现构建 | 验证部署的代码是否与公共源代码匹配 |
| 加密联系人目录 | 联系人记录、关系和笔记都是端到端加密的 |

## 仍在计划中

| 功能 | 隐私收益 |
|------|---------|
| 原生接听电话应用 | 不暴露个人电话号码 |

## 汇总表

| 数据类型 | 加密 | 对服务器可见 | 可通过传票获取 |
|-----------|------|--------------|----------------|
| 通话笔记 | 是（端到端） | 否 | 仅密文 |
| 转录文本 | 是（端到端） | 否 | 仅密文 |
| 报告 | 是（端到端） | 否 | 仅密文 |
| 文件附件 | 是（端到端） | 否 | 仅密文 |
| 联系人记录 | 是（端到端） | 否 | 仅密文 |
| 志愿者身份 | 是（端到端） | 否 | 仅密文 |
| 团队/角色元数据 | 是（加密） | 否 | 仅密文 |
| 自定义字段定义 | 是（加密） | 否 | 仅密文 |
| 短信/WhatsApp/Signal 内容 | 是（在您的服务器上） | 否 | 来自您的服务器的密文；提供商可能拥有原始消息 |
| 通话元数据 | 否 | 是 | 是 |
| 来电电话哈希 | HMAC 哈希 | 仅哈希 | 哈希（没有您的密钥无法反转） |
