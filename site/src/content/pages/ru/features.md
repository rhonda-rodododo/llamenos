## Телефония с несколькими провайдерами

**5 голосовых провайдеров** — Выбирайте из Twilio, SignalWire, Vonage, Plivo или самостоятельно размещённого Asterisk. Настройте провайдера в интерфейсе администратора или во время работы мастера настройки. Переключайтесь между провайдерами в любое время без изменения кода.

**Звонки через браузер по WebRTC** — Волонтёры могут отвечать на звонки прямо в браузере, без телефона. Генерация токенов WebRTC для каждого провайдера: Twilio, SignalWire, Vonage и Plivo. Настройка предпочтений звонков для каждого волонтёра (телефон, браузер или оба).

## Маршрутизация звонков

**Параллельный звонок** — Когда поступает звонок, все волонтёры на смене и не занятые разговором получают вызов одновременно. Первый ответивший принимает звонок; остальные звонки прекращаются мгновенно.

**Планирование по сменам** — Создавайте повторяющиеся смены с конкретными днями и часами. Назначайте волонтёров на смены. Система автоматически направляет звонки тем, кто на дежурстве.

**Очередь с музыкой ожидания** — Если все волонтёры заняты, звонящие попадают в очередь с настраиваемой музыкой ожидания. Время ожидания в очереди регулируется (30-300 секунд). Если никто не отвечает, звонки переходят на голосовую почту.

**Резервная голосовая почта** — Звонящие могут оставить голосовое сообщение (до 5 минут), если ни один волонтёр не ответил. Голосовые сообщения транскрибируются с помощью Whisper AI и шифруются для просмотра администратором.

## Зашифрованные заметки

**Сквозное шифрование заметок** — Волонтёры пишут заметки во время и после звонка. Заметки шифруются на стороне клиента с помощью ECIES (secp256k1 + XChaCha20-Poly1305) перед уходом из браузера. Сервер хранит только зашифрованный текст.

**Двойное шифрование** — Каждая заметка шифруется дважды: один раз для волонтёра, который её написал, и один раз для администратора. Оба могут расшифровать независимо. Никто другой не может прочитать содержимое.

**Пользовательские поля** — Администраторы определяют пользовательские поля для заметок: текст, число, выбор, флажок, текстовая область. Поля шифруются вместе с содержимым заметки.

**Автосохранение черновиков** — Заметки автоматически сохраняются в виде зашифрованных черновиков в браузере. Если страница перезагрузится или волонтёр уйдёт, его работа сохранится. Черновики стираются при выходе из системы.

## Транскрипция ИИ

**Транскрипция на устройстве** — Звонки транскрибируются с помощью ИИ, полностью работающего в браузере волонтёра. Аудио никогда не покидает устройство. Хранится только зашифрованная транскрипция.

**Управление администратором и волонтёром** — Администраторы могут глобально включать или отключать транскрипцию. Волонтёры могут отказаться индивидуально. Оба переключателя независимы.

**Зашифрованные транскрипции** — Транскрипции используют то же шифрование ECIES, что и заметки. Хранимая транскрипция — это только зашифрованный текст.

## Борьба со спамом

**Голосовая CAPTCHA** — Опциональное обнаружение голосовых ботов: звонящий слышит случайное 4-значное число и должен ввести его на клавиатуре. Блокирует автоматический набор, оставаясь доступным для реальных звонящих.

**Ограничение скорости** — Скользящее окно ограничения скорости для каждого номера телефона, сохраняемое в базе данных. Настраиваемые пороги сохраняются после перезагрузки.

**Списки запретов в реальном времени** — Администраторы управляют списками запрещённых номеров телефонов с помощью одиночного ввода или массового импорта. Запреты вступают в силу немедленно. Заблокированные звонящие слышат сообщение об отказе.

**Пользовательские IVR-подсказки** — Записывайте пользовательские голосовые подсказки для каждого поддерживаемого языка. Система использует ваши записи для IVR-потоков, возвращаясь к синтезу речи при отсутствии записи.

## Многоканальный обмен сообщениями

**SMS** — Входящие и исходящие SMS-сообщения через Twilio, SignalWire, Vonage или Plivo. Автоответ с настраиваемыми приветственными сообщениями. Сообщения отображаются в виде разветвлённых бесед.

**WhatsApp Business** — Подключение через Meta Cloud API (Graph API v21.0). Поддержка шаблонных сообщений для начала бесед в 24-часовом окне обмена сообщениями. Поддержка медиасообщений для изображений, документов и аудио.

**Signal** — Обмен сообщениями с акцентом на конфиденциальность через самостоятельно размещённый мост signal-cli-rest-api. Мониторинг состояния с плавной деградацией. Транскрипция голосовых сообщений через Whisper AI на устройстве.

**Разветвлённые беседы** — Все каналы обмена сообщениями отображаются в едином представлении беседы. Пузырьки сообщений с временными метками и индикаторами направления. Обновления в реальном времени. Все сообщения шифруются на вашем сервере сразу по прибытии. Сервер хранит только зашифрованный текст.

## Зашифрованные отчёты

**Роль репортёра** — Специальная роль для людей, подающих советы или отчёты. Репортёры видят только упрощённый интерфейс с отчётами и справкой. Приглашаются через тот же процесс, что и волонтёры, с выбором роли.

**Зашифрованные отправления** — Текст отчёта шифруется с помощью ECIES перед уходом из браузера. Обычные текстовые заголовки — для сортировки, зашифрованное содержимое — для конфиденциальности. Вложения шифруются отдельно.

**Рабочий процесс отчётов** — Категории для организации отчётов. Отслеживание статуса (открыт, взят в работу, решён). Администраторы могут брать отчёты в работу и отвечать зашифрованными ответами в беседах.

## Контактная директория

**Зашифрованные контактные записи** — Храните контактную информацию со сквозным шифрованием. Имена, номера телефонов, электронная почта и заметки шифруются перед уходом из браузера.

**Отслеживание отношений** — Связывайте контакты друг с другом, а также со звонками, беседами и отчётами. Составьте полную картину о тех, кому вы помогаете.

**Автоматическое связывание** — Входящие звонки и сообщения автоматически связываются с известными контактами по совпадению номеров телефонов.

**Доступ на основе команд** — Контролируйте, какие члены команды могут видеть какие контакты. Разрешения детализированы и настраиваемы.

**Теги и приём** — Организуйте контакты с помощью тегов. Рабочие процессы приёма направляют новые контакты на рассмотрение.

**Массовый импорт/экспорт** — Импортируйте контакты из CSV или JSON. Экспортируйте зашифрованные резервные копии. Вся обработка происходит в вашем браузере.

## Настраиваемые разрешения

**Пользовательские роли** — Определяйте собственные роли с точными разрешениями, которые вам нужны. Начните со встроенных шаблонов (Администратор, Волонтёр, Репортёр) или создайте с нуля.

**Детализированные разрешения** — Более 90 отдельных разрешений в 17 областях функций. Контролируйте, кто может просматривать, создавать, редактировать и удалять на детальном уровне.

**Ограничение по командам** — Назначайте членов команд на команды. Разрешения могут быть ограничены конкретными командами, так что разные группы видят разные данные.

## Панель администратора

**Мастер настройки** — Пошаговая настройка при первом входе администратора. Выберите, какие каналы включить (Голос, SMS, WhatsApp, Signal, Отчёты), настройте провайдеров и задайте название горячей линии.

**Чеклист начала работы** — Виджет панели для отслеживания прогресса настройки: конфигурация каналов, адаптация волонтёров, создание смен.

**Мониторинг в реальном времени** — Просматривайте активные звонки, звонящих в очереди, беседы и статус волонтёров в реальном времени. Метрики обновляются мгновенно.

**Управление пользователями** — Приглашайте новых членов команды через безопасные ссылки. Они создают свои собственные учётные записи и ключи шифрования. Управляйте ролями, разрешениями и назначениями в команды.

**Журнал аудита** — Каждый отвеченный звонок, созданная заметка, отправленное сообщение, поданный отчёт, изменённая настройка и административное действие записываются. Постраничный просмотрщик для администраторов.

**История звонков** — История звонков с поиском и фильтрацией по диапазонам дат, поиску номеров телефонов и назначениям волонтёров. Экспорт данных, соответствующий GDPR.

**Встроенная справка** — Разделы FAQ, руководства по ролям, быстрые справочные карточки для горячих клавиш и безопасности. Доступ из боковой панели и командной палитры.

## Опыт волонтёра

**Командная палитра** — Нажмите Ctrl+K (или Cmd+K на Mac) для мгновенного доступа к навигации, поиску, быстрому созданию заметок и переключению тем. Команды только для администраторов фильтруются по ролям.

**Уведомления в реальном времени** — Входящие звонки запускают браузерный звонок, push-уведомление и мигающий заголовок вкладки. Переключайте каждый тип уведомления независимо в настройках.

**Присутствие волонтёров** — Администраторы видят количество волонтёров онлайн, офлайн и на перерыве в реальном времени. Волонтёры могут переключать переключатель перерыва на боковой панели, чтобы временно приостановить входящие звонки, не покидая смену.

**Горячие клавиши** — Нажмите ? чтобы увидеть все доступные сочетания клавиш. Перемещайтесь по страницам, открывайте командную палитру и выполняйте частые действия, не прикасаясь к мыши.

**Автосохранение черновиков заметок** — Заметки автоматически сохраняются в виде зашифрованных черновиков в браузере. Если страница перезагрузится или волонтёр уйдёт, его работа сохранится. Черновики стираются из localStorage при выходе из системы.

**Зашифрованный экспорт данных** — Экспортируйте заметки в виде зашифрованного файла (.enc), соответствующего GDPR, защищённого вашим многофакторным ключом шифрования. Только оригинальный автор может расшифровать экспорт.

**Тёмная/светлая темы** — Переключайтесь между тёмным режимом, светлым режимом или следованием системной теме. Предпочтение сохраняется для каждой сессии.

## Мультиязычность и мобильность

**12+ языков** — Полные переводы интерфейса: английский, испанский, китайский, тагалог, вьетнамский, арабский, французский, гаитянский креольский, корейский, русский, хинди, португальский и немецкий. Поддержка RTL для арабского.

**Прогрессивное веб-приложение** — Устанавливается на любое устройство через браузер. Service worker кеширует оболочку приложения для офлайн-запуска. Push-уведомления для входящих звонков.

**Дизайн mobile-first** — Адаптивный макет, разработанный для телефонов и планшетов. Скрываемая боковая панель, дружественные к сенсорному вводу элементы управления и адаптивные макеты.

## Аутентификация и управление ключами

**Многофакторная защита ключей** — Ваш ключ шифрования защищён до тремя независимыми факторами: PIN-код, выбранный вами, ваш аккаунт поставщика идентификации и опциональный аппаратный ключ безопасности. Компрометация любого одного фактора недостаточна.

**Интеграция с поставщиком идентификации** — Самостоятельное управление идентификацией (под вашим контролем). Адаптация на основе приглашений — никакого обмена секретными ключами. Удалённая отмена сессий — заблокируйте скомпрометированное устройство из любой точки.

**Автоматическое управление сессиями** — Сессии тихо обновляются в фоновом режиме. Автоматическая блокировка при бездействии защищает устройства без присмотра. Ваш ключ шифрования живёт в изолированном процессе, никогда не доступном со страницы.

**Связывание устройств** — Безопасная настройка новых устройств. Отсканируйте QR-код или введите короткий код подготовки. Используется эфемерный обмен ключами — ваш секретный ключ никогда не подвергается при передаче.

**Ключи восстановления** — Во время адаптации вы получаете ключ восстановления на случай чрезвычайных ситуаций. Обязательное зашифрованное резервное копирование перед продолжением.

**Аппаратные ключи безопасности** — Опциональная поддержка passkey для входа, устойчивого к фишингу. Зарегистрируйте аппаратный ключ или биометрию, а затем входите без ввода учётных данных.

**Прямая секретность для каждой заметки** — Каждая заметка шифруется с помощью уникального случайного ключа, затем этот ключ упаковывается через ECIES для каждого авторизованного читателя. Компрометация ключа идентификации не раскрывает прошлые заметки.
