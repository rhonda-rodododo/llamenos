## Если ваш хостинг-провайдер получит повестку

| Они МОГУТ предоставить | Они НЕ МОГУТ предоставить |
|------------------------|---------------------------|
| Метаданные звонков/сообщений (время, длительность) | Содержимое заметок, транскрипции, тексты отчётов |
| Зашифрованные blob базы данных | Имена волонтёров (сквозное шифрование) |
| Какие учётные записи волонтёров были активны и когда | Записи контактной директории (сквозное шифрование) |
| | Содержимое сообщений (шифруется при получении, хранится как зашифрованный текст) |
| | Ключи расшифровки (защищены вашим PIN-кодом, аккаунтом поставщика идентификации и опциональным аппаратным ключом безопасности) |
| | Ключи шифрования для каждой заметки (эфемерные — уничтожаются после упаковки) |
| | Ваш секрет HMAC для обратного преобразования хешей телефонов |

**Сервер хранит данные, которые не может прочитать.** Метаданные (когда, как долго, какие учётные записи) видимы. Содержимое (что было сказано, что было написано, кто ваши контакты) — нет.

## По функциям

Ваша уязвимость для конфиденциальности зависит от включённых каналов:

### Голосовые звонки

| Если вы используете... | Возможный доступ третьих лиц | Возможный доступ сервера | Сквозное зашифрованное содержимое |
|------------------------|-----------------------------|--------------------------|-----------------------------------|
| Twilio/SignalWire/Vonage/Plivo | Аудио звонка (в реальном времени), записи звонков | Метаданные звонков | Заметки, транскрипции |
| Самостоятельно размещённый Asterisk | Ничего (под вашим контролем) | Метаданные звонков | Заметки, транскрипции |
| Браузер-браузер (WebRTC) | Ничего | Метаданные звонков | Заметки, транскрипции |

**Повестка телефонному провайдеру**: У них есть детализация звонков (время, номера телефонов, длительность). У них НЕТ заметок к звонкам или транскрипций. Запись по умолчанию отключена.

**Транскрипция**: Транскрипция происходит полностью в вашем браузере с помощью ИИ на устройстве. **Аудио никогда не покидает ваше устройство.** Хранится только зашифрованная транскрипция.

### Текстовые сообщения

| Канал | Доступ провайдера | Хранение на сервере | Примечания |
|-------|------------------|---------------------|------------|
| SMS | Ваш телефонный оператор читает все сообщения | **Зашифровано** | Провайдер хранит оригинальные сообщения |
| WhatsApp | Meta читает все сообщения | **Зашифровано** | Провайдер хранит оригинальные сообщения |
| Signal | Сеть Signal сквозно зашифрована, но мост расшифровывает при получении | **Зашифровано** | Лучше SMS, но не zero-knowledge |

**Сообщения шифруются сразу по прибытии на ваш сервер.** Сервер хранит только зашифрованный текст. Ваш телефонный оператор или провайдер обмена сообщениями может по-прежнему хранить оригинальное сообщение — это ограничение данных платформ, а не то, что мы можем изменить.

**Повестка провайдеру обмена сообщениями**: SMS-провайдеры имеют полное содержимое сообщений. Meta имеет содержимое WhatsApp. Сообщения Signal сквозно зашифрованы до моста, но мост (работающий на вашем сервере) расшифровывает перед повторным шифрованием для хранения. Во всех случаях **на вашем сервере только зашифрованный текст** — хостинг-провайдер не может прочитать содержимое сообщений.

### Заметки, транскрипции и отчёты

Всё содержимое, написанное волонтёрами, зашифровано сквозным шифрованием:

- Каждая заметка использует **уникальный случайный ключ** (прямая секретность — компрометация одной заметки не компрометирует остальные)
- Ключи отдельно упаковываются для волонтёра и каждого администратора
- Сервер хранит только зашифрованный текст
- Расшифровка происходит в браузере
- **Пользовательские поля, содержимое отчётов и вложения шифруются отдельно**

**Изъятие устройства**: Без вашего PIN-кода **И** доступа к вашему аккаунту поставщика идентификации злоумышленники получают только зашифрованный blob, который вычислительно невозможно расшифровать. Если вы также используете аппаратный ключ безопасности, **три независимых фактора** защищают ваши данные.

## Конфиденциальность номеров телефонов волонтёров

Когда волонтёры отвечают на звонки со своих личных телефонов, их номера становятся известны вашему телефонному провайдеру.

| Сценарий | Номер телефона виден |
|----------|----------------------|
| PSTN-звонок на телефон волонтёра | Телефонный провайдер, оператор связи |
| Браузер-браузер (WebRTC) | Никому (аудио остаётся в браузере) |
| Самостоятельно размещённый Asterisk + SIP-телефон | Только вашему серверу Asterisk |

**Для защиты номеров телефонов волонтёров**: Используйте звонки через браузер (WebRTC) или предоставьте SIP-телефоны, подключённые к самостоятельно размещённому Asterisk.

## Недавно выпущено

Эти улучшения уже работают:

| Функция | Преимущество для конфиденциальности |
|---------|-------------------------------------|
| Зашифрованное хранение сообщений | SMS, WhatsApp и Signal сообщения хранятся как зашифрованный текст на вашем сервере |
| Транскрипция на устройстве | Аудио никогда не покидает ваш браузер — полностью обрабатывается на устройстве |
| Многофакторная защита ключей | Ваши ключи шифрования защищены PIN-кодом, поставщиком идентификации и опциональным аппаратным ключом |
| Аппаратные ключи безопасности | Физические ключи добавляют третий фактор, который нельзя скомпрометировать удалённо |
| Воспроизводимые сборки | Проверьте, что развёрнутый код соответствует публичному исходному коду |
| Зашифрованная контактная директория | Контактные записи, отношения и заметки сквозно зашифрованы |
