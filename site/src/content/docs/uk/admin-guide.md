Як адміністратор ви керуєте всім: волонтерами, змінами, каналами зв’язку, розмовами, повідомленнями, списками заборон та користувацькими полями. Цей посібник охоплює ключові робочі процеси адміністратора.

## Вхід у систему

Увійдіть за допомогою `nsec` (секретного ключа Nostr), згенерованого під час [налаштування](/docs/getting-started). Сторінка входу приймає формат nsec (`nsec1...`). Ваш браузер підписує виклик ключем — секрет ніколи не покидає пристрій.

За бажанням зареєструйте WebAuthn passkey у налаштуваннях для входу без пароля на додаткових пристроях.

## Майстер налаштування

Під час першого входу додаток перенаправляє до **майстра налаштування** — покрокового процесу:

1. **Назвіть свою гарячу лінію** — встановіть відображувану назву для користувачів
2. **Оберіть канали** — увімкніть/вимкніть Голос, SMS, WhatsApp, Signal та Повідомлення
3. **Налаштуйте провайдерів** — введіть облікові дані для кожного увімкненого каналу
4. **Перевірка** — підтвердіть налаштування та завершіть установку

Після завершення майстра встановлюється прапорець `setupCompleted` і майстер більше не з’являється. Ви завжди можете змінити ці налаштування пізніше на сторінці Налаштувань.

## Керування волонтерами

Перейдіть до **Волонтерів** у бічній панелі, щоб:

- **Додати волонтера** — генерує нову пару ключів Nostr. Безпечно поділіться nsec із волонтером (він показується лише раз).
- **Створити посилання для запрошення** — генерує одноразове посилання. Процес запрошення включає вибір ролі (волонтер, адміністратор або репортер).
- **Редагувати** — оновити ім’я, номер телефону та роль.
- **Видалити** — деактивувати доступ волонтера.

Номери телефонів волонтерів видимі лише адміністраторам. Вони використовуються для паралельного дзвінка, коли волонтер перебуває на зміні.

## Керування репортерами

Репортери — це спеціальна роль для людей, які надсилають поради або повідомлення через платформу. Вони мають обмежений доступ — можуть переглядати лише власні повідомлення та сторінку довідки.

Щоб додати репортера:
1. Створіть посилання для запрошення та виберіть роль **Репортер**
2. Поділіться посиланням із репортером — він створить власні облікові дані
3. Репортери входять у систему та бачать спрощений інтерфейс лише з Повідомленнями та Довідкою

## Налаштування змін

Перейдіть до **Змін**, щоб створювати повторювані розклади:

1. Натисніть **Додати зміну**
2. Встановіть назву, виберіть дні тижня та встановіть час початку/закінчення
3. Призначте волонтерів на зміну
4. Збережіть

Система автоматично спрямовує дзвінки волонтерам, які перебувають на чергуванні.

## Канали та провайдери

Перейдіть до **Налаштувань → Канали**, щоб керувати голосовими та обмінними повідомленнями:

- **Голос** — виберіть провайдера (Twilio, SignalWire, Vonage, Plivo, Asterisk)
- **SMS** — увімкніть SMS через вашого голосового провайдера
- **WhatsApp** — підключіть WhatsApp Business через Meta Cloud API
- **Signal** — налаштуйте міст signal-cli-rest-api
- **Повідомлення** — увімкніть роль репортера для подання зашифрованих повідомлень

Для кожного каналу введіть необхідні облікові дані та вкажіть URL вебхуків.

## Списки заборон

Перейдіть до **Заборони**, щоб керувати небажаними абонентами:

- **Додати заборону** — заблокуйте конкретний номер телефону
- **Масовий імпорт** — завантажте CSV з номерами для блокування
- **Тривалість** — встановіть постійну або тимчасову заборону
- **Повідомлення** — налаштуйте повідомлення, яке почують заблоковані абоненти

Заборони набувають чинності негайно.

## Користувацькі поля для нотаток

Перейдіть до **Налаштувань → Нотатки**, щоб визначити користувацькі поля для нотаток волонтерів:

- Текст
- Число
- Вибір (випадаючий список)
- Прапорець
- Текстова область

Ці поля шифруються разом із вмістом нотатки.

## Моніторинг та аудит

- **Активні дзвінки** — переглядайте поточні дзвінки та черги в реальному часі
- **Журнал аудиту** — кожен дзвінок, нотатка, повідомлення, звіт та зміна налаштувань записується
- **Історія дзвінків** — шукайте та фільтруйте дзвінки за датою та номером телефону

## Експорт даних

Адміністратори можуть експортувати дані відповідно до GDPR. Експорт нотаток шифрується та може бути розшифрований лише автором.
