## စေတနာ့ဝန်ထမ်းဆိုတာ ဘာလဲ?

စေတနာ့ဝန်ထမ်းသည် ခေါ်ဆိုမှု၊ သတင်းစကားနှင့် အစီရင်ခံချက်များကို လက်ခံသဖြင့် လုံခြုံရေးရှိသော မှတ်စုများရေးသားသော ပုဂ္ဂလိကတစ်ဦး ဖြစ်သည်။ စေတနာ့ဝန်ထမ်းများသည် အက်ဒမင်မဖြစ်ဘဲ ပူးပေါင်းဆောင်ရွက်နိုင်သည်။

## အသံခေါ်ဆိုမှုများ

### ခေါ်ဆိုမှုကို ဘယ်လိုဖြေကြားမလဲ?

သင် Shift တွင် ရှိနေပြီး Active ဖြစ်နေသောအခါ ခေါ်ဆိုမှုသည် တိုက်ရိုက်သင့်သော Browser သို့ ဝင်ရောက်လာမည်။

- **ခေါ်ဆိုမှု၏ အစောင့်ကြည့်ခြင်း** — Browser ၏ စာမျက်နှာသည် ခေါ်ဆိုမှု Screen သို့ ပြောင်းလဲသွားမည်။
- **ခေါ်ဆိုမှုကို လက်ခံခြင်း** — **Take Call** ကို နှိပ်ခြင်း သို့မဟုတ် မိမိဖက်မှ လက်ခံခြင်း။
- **မှတ်စုများရေးသားခြင်း** — ခေါ်ဆိုမှုအတွင်း လုံခြုံရေးရှိသော မှတ်စုများကို မှတ်စုခွက်ထဲတွင် ရေးသားပါ။
- **ခေါ်ဆိုမှုကို ပြီးဆုံးခြင်း** — အရာအားလုံး ပြီးစီး၍ကျပန်းဖြစ်လျှင် **End Call** ကို နှိပ်ပါ။

### မရောက်ခဲ့လျှင်?

မရောက်ခဲ့ပါက ခေါ်ဆိုမှုကို အခြားစေတနာ့ဝန်ထမ်းထံ လွှဲပြောင်းနိုင်သည် သို့မဟုတ် Voice Mail သို့ သွားနိုင်သည်။ အက်ဒမင်သည် Settings တွင် ဤအရာကို ထိန်းချုပ်နိုင်သည်။

### အနားယူချင်လျှင်?

Sidebar တွင် **On Break** ကို ရွေးချယ်နိုင်သည်။ ဤအရာသည် ခေါ်ဆိုမှုအသစ်များကို ရပ်တန့်ထားပြီး သင်၏ Shift တွင် ရှိနေဆဲဖြစ်သည်။

## လုံခြုံရေးရှိသော မှတ်စု

### လုံခြုံရေးရှိသော မှတ်စုဆိုတာ ဘာလဲ?

သင်ရေးသားသော မှတ်စုတိုင်းမှာ **Browser မှ မထွက်ခင် ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်**။ ဤအရာက Server သည် ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Code သာလျှင် မြင်ရပြီး သင့်အကြောင်းအရာကို မမြင်ရဟု ဆိုလိုသည်။

### မှတ်စုများကို ဘယ်လိုရေးသားမလဲ?

1. ခေါ်ဆိုမှုအတွင်း သို့မဟုတ် ပြီးနောက် **+ New Note** ကို နှိပ်ပါ။
2. အက်ဒမင် သတ်မှတ်ထားသော မေးခွန်းများကို ဖြေကြားပါ (အကယ်ရှိလျှင်)။
3. သင်၏ မှတ်စုအကြောင်းအရာကို ရေးသားပါ။
4. **Save** ကို နှိပ်ပါ။

### စာမျက်နှာ Reload ဖြစ်သွားလျှင်?

သင့် မှတ်စုများသည် မျှတစ်ခါတည်း 10 စက္ကန့်လျှင် **ကုဗ္ဌအကာအကြယ်ထည့်ထားသော Draft** အဖြစ် Browser တွင် သိမ်းဆည်းထားသည်။ စာမျက်နှာ Reload ဖြစ်သွားသော် သို့မဟုတ် ထွက်ခွာသွားလျှင် သင့်လုပ်ငန်းများကို မပျက်ပါ။ Logout လုပ်သောအခါမှသာ Draft များကို ရှင်းလင်းပစ်သည်။

### မှတ်စုများကို Export လုပ်နိုင်သလား?

ဟုတ်ကဲ့။ Panel တွင် **Export Notes** ရွေးစရာ ရှိသည်။ ဤအရာသည် သင့်မှတ်စုများကို ကုဗ္ဌအကာအကြယ်ထည့်ထားသော ဖိုင် (.enc) အဖြစ် Download လုပ်ပေးမည်။ သင်၏မှတ်စုများရေးသားခဲ့သော စက်ပိုင်းပေါ်မှသာ ဖွင့်နိုင်သည်။

## သတင်းစကားနှင့် အစီရင်ခံချက်

### SMS / WhatsApp / Signal

သတင်းစကားရောက်လာသောအခါ အသိပေးချက်တစ်ခု ရရှိမည်။ တိုက်ရိုက်အဖြေပို့နိုင်သည် သို့မဟုတ် Conversation History တွင် ကြည့်ရှုနိုင်သည်။

### အစီရင်ခံပေးသူ၏ အစီရင်ခံချက်

သင့်အား Assign လုပ်ထားသော အစီရင်ခံချက်တစ်ခုအပေါ် သင့်တွင် ခွင့်ပြုချက်ရှိလျှင် အကြောင်းအရာကို ဖတ်ရှုနိုင်သည်။ အစီရင်ခံချက်၏ အကြောင်းအရာအားလုံးလည်း သိမ်းဆည်းခံရမည့်အခါ ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။

## ဘယ်လို စက်ပိုင်းများကို အသုံးပြုနိုင်သလား?

Chrome၊ Firefox၊ Safari၊ Edge နှင့် ခေတ်မီ Browser များတွင် အလုပ်လုပ်သည်။ Mobile တွင် အသုံးပြုလိုပါက PWA အား သင့်ပါးလွှာသို့ ထည့်သွင်းထားပါ။

## ထပ်မံ မေးခွန်းများရှိလျှင်

နည်းပညာဆိုင်ရာ သို့မဟုတ် အခြားမေးခွန်းများရှိလျှင် သင့် အက်ဒမင်ကို ဆက်သွယ်ပါ။
