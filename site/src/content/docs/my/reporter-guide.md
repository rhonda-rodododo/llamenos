## ပထမဆုံး အဆင့် — အကောင့်ဖွင့်ခြင်း

သင့်ကို ဖိတ်ခေါ်သောအခါ လုံခြုံသော Link တစ်ခု ရရှိမည်။

1. **Link ကို နှိပ်ပါ** နှင့် ခိုင်မာသော PIN ကို ရွေးချယ်ပါ။
2. **Recovery Key ကို သိမ်းဆည်းပါ** — ဤအရာသည် အရေးပေါ်အခြေအနေအတွက် ဖြစ်သည်။
3. **ဝင်ရောက်ပါ** — ယခု သင် Reporter Dashboard သို့ ရောက်ရှိနေပါပြီ။

## အစီရင်ခံချက် အသစ်ပို့ခြင်း

1. **New Report** ကို နှိပ်ပါ။
2. **ခေါင်းစဉ်** ရေးသားပါ — ဤအရာကို လူအားလုံးမြင်နိုင်သည် (အမျိုးအစား ခွဲခြားရန်)။
3. **အစီရင်ခံချက် အကြောင်းအရာ** ရေးသားပါ — ဤအရာကို **Browser မှ မထွက်ခင် လုံးဝ ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်**။
4. ရှိလျှင် **ဖိုင်များကို ချိတ်ဆက်ပါ** — တစ်ခုချင်းစီကို ခွဲခြားပြီး ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။
5. **Submit** ကို နှိပ်ပါ။

> **အရေးကြီးသော မှတ်ချက် —** သင်နှင့် ခွင့်ပြုထားသော အဖွဲ့အစည်းဝင်များသာလျှင် သင့်၏ ကုဗ္ဌအကာအကြယ်ထည့်ထားသော အကြောင်းအရာကို ဖတ်ရှုနိုင်သည်။ Server သည် Ciphertext သာလျှင် မြင်ရသည်။

## မိမိ၏ အစီရင်ခံချက်ကို စောင့်ကြည့်ခြင်း

အစီရင်ခံချက် ပို့ပြီးနောက် **My Reports** စာရင်းတွင် အခြေအနေကို ကြည့်ရှုနိုင်သည်။

- **Submitted** — စစ်ဆေးမှုအတွက် စောင့်နေဆဲ။
- **In Review** — တစ်စုံတစ်ယောက်က လုပ်ဆောင်နေပြီ။
- **Resolved** — ဖြေရှင်းပြီးပြီ။

အက်ဒမင်မှ အဖြေပေးလာလျှင် အစီရင်ခံချက် အတွင်းတွင် ဖတ်ရှုနိုင်သည်။ ဤအဖြေသည်လည်း ကုဗ္ဌအကာအကြယ်ထည့်ထားသည်။

## မိမိ၏ပရိုဖိုင်ကို စီမံခန့်ခွဲခြင်း

**Settings** အတွင်း၌ သင်နိုင်သည်များမှာ —

- အီးမေးလ် နှင့် ပြေပြစ်သည့် အမည်ကို ပြင်ဆင်ခြင်း
- PIN သို့မဟုတ် ဘိုင်အိုမက်ထရစ်ကို အသစ်ပြောင်းခြင်း
- အကောင့်လှုပ်ရှားမှုကို ကြည့်ရှုခြင်း
- ချိတ်ဆက်ထားသော စက်ပိုင်းများကို စီမံခန့်ခွဲခြင်း

## ဝင်ရောက်လို့ မရလျှင်?

- **PIN မေ့သွားလျှင်** — **Forgot PIN** ကို နှိပ်ပြီး အီးမေးလ်ဖြင့် ရောက်လာသော ညွှန်ကြားချက်များကို လိုက်နာပါ။
- **အကောင့်ကို ပိတ်ပင်ထားလျှင်** — သင့် အက်ဒမင်ကို ဆက်သွယ်ပါ။
- **စက်ပိုင်း အသစ်ဖြစ်လျှင်** — အကောင့်နှင့် ချိတ်ဆက်ရန် လုံခြုံရေးရှိသော လုပ်ထုံးလုပ်နည်းလိုအပ်သည်။ ဝင်ရောက်ခြင်း Screen တွင် **Add Device** ကို ရွေးချယ်ပါ။
