## ပထမဆုံး ဝင်ရောက်ခြင်း

1. **ဖိတ်ခေါ်သည့်အီးမေးလ်ကို လိုက်နာပါ** — သင်လုံခြုံသော လင့်ခ်တစ်ခု ရရှိမည်။ ထိုလင့်ခ်ကို နှိပ်ပြီး မိမိ၏ အကောင့်ကို ခိုင်မာသော စကားဝှက်ဖြင့် ဖန်တီးပါ။
2. **မိမိ၏စက်ပိုင်းကို ပြေကျင်းပါ** — မိမိ၏ PIN ကို ရွေးချယ်ပါ၊ ဘိုင်အိုမက်ထရစ်/လုံခြုံရေး Key ကို ဖွင့်ပါ၊ နှင့် Recovery Key ကို သိမ်းဆည်းပါ။
3. **ဝင်ရောက်ပါ** — ယခု Llamenos ကို အသုံးပြုရန် အသင့်ဖြစ်ပါပြီ။

## 5-မိနစ် လမ်းညွှန်

### 1. Dashboard ကို ကြည့်ရှုပါ

ဝင်ရောက်လာသောအခါ အဓိကခေါင်းစဉ်နှင့် Panel ကို မြင်ရမည်။ ဤနေရာတွင် လိုအပ်သမျှတို့ကို တွေ့ရှိနိုင်သည်။

### 2. ကိုယ်ရေးကိုယ်တာကို ပြင်ဆင်ပါ

အသုံးပြုသူအမည်ပေါ်တွင် နှိပ်ပါ။ ဤနေရာတွင် သင်ဖြစ်နိုင်ချေရှိသည်များမှာ —

- ပရိုဖိုင်းပုံကို ပြောင်းလဲခြင်း
- အခြေခံ ဆက်သွယ်ရန် အချက်အလက်များကို ပြင်ဆင်ခြင်း
- အသိပေးချက် ဦးစားပေးချက်များကို ပြေကျင်းခြင်း
- မိမိ၏စက်ပိုင်း မှတ်တမ်းကို ကြည့်ရှုခြင်း

### 3. အက်ဒမင် လမ်းညွှန် (အက်ဒမင်များအတွက်)

အက်ဒမင်ဖြစ်ပါက သင်ဖြစ်နိုင်ချေရှိသည်များမှာ —

- အသုံးပြုသူများကို ဖိတ်ခေါ်ခြင်း
- Shift နှင့် Schedule များကို ပြေကျင်းခြင်း
- လှုပ်ရှားမှုမှတ်တမ်းများနှင့် ခေါ်ဆိုမှု မှတ်တမ်းကို ကြည့်ရှုခြင်း
- ဘာသာစကား၊ အဖွဲ့အစည်း Logo နှင့် ဆက်သွယ်ရန် အချက်အလက်များကို ပြင်ဆင်ခြင်း

### 4. စေတနာ့ဝန်ထမ်း လမ်းညွှန် (စေတနာ့ဝန်ထမ်းများအတွက်)

စေတနာ့ဝန်ထမ်းဖြစ်ပါက သင်ဖြစ်နိုင်ချေရှိသည်များမှာ —

- အက်ဒမင်မှ တဆင့် လာသော ခေါ်ဆိုမှုများကို ဖြေကြားခြင်း
- လုံခြုံရေးရှိသော မှတ်စုများရေးသားခြင်း
- သတင်းစကား စကားပြောဆိုမှုများကို စောင့်ကြည့်ခြင်း
- Real-Time တွင် မိမိ၏ အခြေအနေကို ပြောင်းလဲခြင်း

### 5. အစီရင်ခံပေးသူ လမ်းညွှန် (အစီရင်ခံပေးသူများအတွက်)

အစီရင်ခံပေးသူဖြစ်ပါက သင်ဖြစ်နိုင်ချေရှိသည်များမှာ —

- အစီရင်ခံချက် အသစ်တင်ပြခြင်း
- ယခင် အစီရင်ခံချက်များ၏ အခြေအနေကို ကြည့်ရှုခြင်း
- လုံခြုံရေးရှိသော အဖြေများကို ဖတ်ရှုခြင်း

## ဘယ်လို Browser / စက်ပိုင်း?

Llamenos သည် ခေတ်မီ Browser အများစုတွင် အလုပ်လုပ်သည်။ အနည်းဆုံးအားဖြင့် အောက်ပါတို့ထဲမှ တစ်ခု လိုအပ်သည် —

- Chrome / Edge / Firefox / Safari (အသစ်များ)
- iOS Safari (iOS 14+)
- Android Chrome

အကောင်းဆုံး အတွေ့အကြုံအတွက် PWA အား သင့်ပါးလွှာသို့ ထည့်သွင်းထားပါ။

## မေးခွန်းများရှိပါက?

လမ်းညွှန်များအကြား မသေချာမှုရှိပါက [စေတနာ့ဝန်ထမ်း လမ်းညွှန်](volunteer-guide) သို့မဟုတ် [အက်ဒမင် လမ်းညွှန်](admin-guide) ကို နှိပ်ကြည့်ပါ။
