## Llamenos ဆိုတာ ဘာလဲ?

Llamenos သည် **ပြီးပြည့်စုံသော ထိန်းချုပ်မှု ရှိသော အရေးပေါ်ကူညီရေး ပလက်ဖောင်း** ဖြစ်သည်။ အသိုင်းအဝိုင်း အဖွဲ့အစည်းများနှင့် အရေးပေါ်ကူညီရေး အဖွဲ့များအတွက် တည်ဆောက်ထားသည်။ ၎င်းသည် တစ်ခုတည်းသော စနစ်အဖြစ် လုပ်ကိုင်ပြီး လိုအပ်သမျှတို့ကို ထည့်သွင်းထားသည်။

- **WebRTC ဖြင့် အသံခေါ်ဆိုမှုများ**
- **SMS၊ WhatsApp နှင့် Signal** စကားပြောဆိုမှု တစ်စုတည်းဖြင့်
- **လုံခြုံရေးရှိသော မှတ်စုများ**
- **လုံခြုံရေးရှိသော အစီရင်ခံချက်များ** အများပြည်သူသို့ မှတ်တမ်းတင်ရန်

## ဘယ်လိုအလုပ်လုပ်သလဲ

စနစ်တစ်ခုလုံးအနေဖြင့် Llamenos တွင် အခြေခံရ_throw ၃ ခုရှိသည်။ သင့်ရ_throwအလိုက် ဘာများမျှော်လင့်ရမည်ကို လေ့လာပါ။

### 1. အက်ဒမင် (Admin)

အက်ဒမင်များသည် စနစ်ကို တည်ဆောက်ခြင်း၊ အသုံးပြုသူများကို စီမံခန့်ခွဲခြင်း နှင့် ဒေသဆိုင်ရာ ဆက်တင်များကို ပြေကျင်းခြင်း ပြုလုပ်ကြသည်။

### 2. စေတနာ့ဝန်ထမ်း (Volunteer)

စေတနာ့ဝန်ထမ်းများသည် အသံခေါ်ဆိုမှုများ၊ သတင်းစကားများ နှင့် အစီရင်ခံချက်များကို လက်ခံသည်။ လုံခြုံရေးရှိသော မှတ်စုများရေးသားပြီး Real-Time တွင် ဆောင်ရွက်ကြသည်။

### 3. အစီရင်ခံပေးသူ (Reporter)

အစီရင်ခံပေးသူများသည် လုံခြုံရေးရှိသည့် သတင်းအချက်အလက်များကို ပို့သည်။ ယခင်အစီရင်ခံချက်များကို စောင့်ကြည့်ပြီး အခြေခံအချက်အလက်များကို ပြင်ဆင်ကြသည်။

## Setup တိုးတက်မှု

Llamenos ကို စတင်အသုံးပြုမည့် အခါတွင် လိုက်နာရမည့် အဆင့်များရှိသည်။ အောက်ပါ အဆင့်များကို ဖတ်ရှုပါ။

1. **အသုံးပြုသူများကို ဖိတ်ခေါ်ပါ** — အက်ဒမင်များသည် အသုံးပြုသူများကို အီးမေးလ်ဖြင့် ဖိတ်ခေါ်သည်။
2. **အသင်းများကို စီစဉ်ပါ** — စေတနာ့ဝန်ထမ်းများနှင့် အစီရင်ခံပေးသူများကို စီမံကိန်းအလိုက် ခွဲဝေပါ။
3. **Shift များကို စီစဉ်ပါ** — ခေါ်ဆိုမှုများကို အချိန်နှင့်အမျှ စီမံခန့်ခွဲပါ။
4. **သတင်းပို့ချန်နယ်များကို စီစဉ်ပါ** — Twilio၊ WhatsApp၊ Signal၊ SMS များကို ပြေကျင်းပါ။
5. **အခြေခေျက စောင့်ကြည့်မှုကို ဆက်လက်လုပ်ဆောင်ပါ** — အက်ဒမင်သည် Dashboard ပေါ်တွင် အားလုံးကို မျက်ချပ် စောင့်ကြည့်သည်။

ပိုမိုသိရှိလိုပါက သင့်ရ_throwအလိုက် လမ်းညွှန်များကို နှိပ်ပါ။
