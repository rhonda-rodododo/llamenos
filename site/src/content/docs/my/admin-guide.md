## အက်ဒမင် စတင်ခြင်း

ပထမဆုံး ဝင်ရောက်သောအခါ Llamenos သည် အချို့အရာများကို ချက်ချင်း Setup လုပ်ရန် အကြံပေးသည်။

### Setup Wizard

1. **ဘာသာစကား နှင့် ဒေသ** ရွေးချယ်ပါ။
2. **အဖွဲ့အစည်း အမည် နှင့် Logo** ထည့်သွင်းပါ။
3. **ဆက်သွယ်ရေးချန်နယ်များကို ဖွင့်ပါ** —
   - Twilio / SignalWire / Vonage / Plivo — ခေါ်ဆိုမှုနှင့် SMS အတွက်
   - WhatsApp Business API
   - Signal Bridge
4. **စတင်သည့် အဖွဲ့များ** ဖန်တီးပါ (နောင်တွင် ပြင်ဆင်နိုင်သည်)။
5. **စတင်သည့် Shift များ** ကို ပြေကျင်းပါ။

## အသုံးပြုသူများကို စီမံခန့်ခွဲခြင်း

### အသုံးပြုသူများကို ဖိတ်ခေါ်ခြင်း

1. **Users > Invite** သို့ သွားပါ။
2. ဖိတ်ခေါ်လိုသော အီးမေးလ်လိပ်စာများကို ရေးသားပါ။
3. **ရ_throw** ရွေးချယ်ပါ (Admin, Volunteer, Reporter)။
4. **Send Invites** နှိပ်ပါ။

အသုံးပြုသူသည် လုံခြုံသော Link ကို ရရှိပြီး မိမိ၏အကောင့်ကို လုံခြုံစွာ Setup လုပ်မည်။ သင်သည် Password သို့မဟုတ် Secret Code ပို့ရန် မလိုအပ်ပါ။

### အခွင့်အရေးများ

အသုံးပြုသူတိုင်းသည် အခြေခံရ_throw များကို တစ်ခု သို့မဟုတ် တစ်ခုထက်ပိုပြီး ရရှိနိုင်သည် —

| ရ_throw | လုပ်နိုင်သည်များ |
|--------|----------------|
| **Admin** | အားလုံး — Setup၊ အသုံးပြုသူ၊ စောင့်ကြည့်ခြင်း၊ ဆက်တင်များ |
| **Volunteer** | ခေါ်ဆိုမှု၊ သတင်းစကား၊ မှတ်စု၊ Assign လုပ်ထားသော အစီရင်ခံချက်များ |
| **Reporter** | မိမိ၏ အစီရင်ခံချက်များသာ ပို့ခြင်း နှင့် စောင့်ကြည့်ခြင်း |

### အသုံးပြုသူများကို ပိတ်ပင်ခြင်း

အကယ်၍ တစ်ဦးဦးကို ဖယ်ရှားရန် သို့မဟုတ် ခွင့်ပြုချက်ကို လျှော့ချရန် လိုအပ်လျှင် —

1. ထိုသူ၏အမည်ပေါ်တွင် နှိပ်ပါ။
2. **Change Role** သို့မဟုတ် **Deactivate Account** ရွေးချယ်ပါ။
3. ပြောင်းလဲမှုကို အတည်ပြုပါ။

> ** သတိပေးချက် —** Deactivate လုပ်ပါ၊ မဖျက်ပါစေနှင့်။ လှုပ်ရှားမှု မှတ်တမ်းကို ထိန်းသိမ်းထားရန်အတွက် ဖြစ်သည်။

## Shift များ နှင့် Schedule

### Shift ဆိုတာ ဘာလဲ?

Shift သည် စေတနာ့ဝန်ထမ်းများ ခေါ်ဆိုမှုများကို လက်ခံသည့် အချိန်ကို သတ်မှတ်သည်။ Llamenos သည် Shift အလိုက် ခေါ်ဆိုမှုများကို လမ်းညွှန်ပေးသည်။

### Shift ဘယ်လိုဖန်တီးမလဲ?

1. **Shifts > New Shift** သို့ သွားပါ။
2. **အမည်၊ အချိန် နှင့် ထပ်ခါထပ်ခါမှု** ကို ပြေကျင်းပါ။
3. **အဖွဲ့ / စေတနာ့ဝန်ထမ်းများ** ထည့်သွင်းပါ။
4. **Save** နှိပ်ပါ။

## စနစ်ကို စောင့်ကြည့်ခြင်း

### Dashboard

ဤနေရာတွင် သင်မြင်နိုင်သည်များမှာ —

- မည်သည့်စေတနာ့ဝန်ထမ်းများ Online ရှိသလဲ
- ခေါ်ဆိုမှု အသီးအသီး Queue တွင် ဘယ်လောက်ရှိသလဲ
- လတ်တလော သတင်းစကားများ နှင့် ဖွင့်ထားသော အစီရင်ခံချက်များ
- ပတ်စဉ်ရက် သို့မဟုတ် လချိန် ခြေရာများ

### ခေါ်ဆိုမှု မှတ်တမ်း

ခေါ်ဆိုမှုတိုင်း၊ သတင်းစကားတိုင်း နှင့် မှတ်စုတိုင်း မှတ်တမ်းတင်ထားသည်။ ရက်စွဲ၊ အမည် သို့မဟုတ် စေတနာ့ဝန်ထမ်း အလိုက် ရှာဖွေနိုင်သည်။ ဤအရာသည် အပြင်ဘက် အစီရင်ခံချက်များနှင့် လေ့လာရန်အတွက် အသုံးဝင်သည်။

### Audit Log

အသေးစိတ် လှုပ်ရှားမှုအားလုံး မှတ်တမ်းတင်ထားသည်။ မည်သူ မည်သည့်အချိန် ဘာလုပ်ခဲ့သည်ကို သိရှိလိုလျှင် **Audit Log** သို့ သွားပါ။

## လုံခြုံရေး ဆက်တင်များ

- **2FA / Passkey** — အက်ဒမင်တိုင်း အသုံးပြုရန် အကြံပြုထားသည်။
- **Session Timeout** — စောင့်ရှောက်မှု မရှိသော စက်ပိုင်းများကို ကာကွယ်ရန်။
- **Export Settings** — မိမိ၏ ဆက်တင်များကို သိမ်းဆည်းရန် သို့မဟုတ် မိတ္တူကူးရန်။

## နောင်လာမည့်ရက်များအတွက် အဆင်သင့်

နေ့စဉ်လုပ်ငန်းများကို ဆက်လက်မလုပ်ဆိုင်မီ အောက်ပါအချက်များကို စစ်ဆေးပါ —

- စေတနာ့ဝန်ထမ်းအားလုံး မှန်ကန်စွာ Login ဝင်ထား
- ပတ်စဉ်ရက် Shift များ ပြေကျင်းထား
- ဆက်သွယ်ရေးချန်နယ်များ မှန်ကန်စွာ လုပ်ဆောင်နေ
- လူတိုင်းအနေဖြင့် အက်ဒမင်ကို ဆက်သွယ်ရန် အချိန်ကို သိကြသည်
