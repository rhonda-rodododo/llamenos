## መጀመሪያ፦ መለያ መፍጠር

ጥሪው ሲደርስብህ ደህንነቱ የተጠበቀ አገናኝ ትደርስሃለህ።

1. **አገናኙን ጠቅ አድርግ** እና ጠንካራ PIN ምረጥ።
2. **የመልሶ ማግኘት ቁልፍህን አስታምክ** — ይህ ለአደጋ ጊዜ ነው።
3. **ግባ** እና በቀጥታ ወደ Reporter Dashboard ትደርሳለህ።

## አዲስ ሪፖርት መላክ

1. **New Report** ጠቅ አድርግ።
2. **ርዕስ ጻፍ** — ይህ ለሁሉም የሚታይ ክፍል ነው (ለምድብ ለማድረግ)።
3. **የሪፖርቱ ይዘት ጻፍ** — ይህ **ከBrowser ከመውጣቱ በፊት ሙሉ በሙሉ ይመሰጠራል**。
4. ካለ፣ **ፋይሎችን ያያይዝ** — እያንዳንዳቸው በነጻ ይመሰጠራሉ።
5. **Submit** ጠቅ አድርግ።

> **ጠቃሚ ምክር፦** አንተ እና የተፈቀደላቸው የቡድን አባላት ብቻ የተመሰጠረውን ይዘት ማንበብ ይችላሉ። Server የኮድ ክፍል ብቻ ያየዋል።

## ሪፖርቱን መከታተል

ሪፖርት ከተላከ በኋላ በ**My Reports** ዝርዝር ውስጥ ሁኔታውን መመልከት ትችላለህ፦

- **Submitted** — ለገመድገድ እየቆመ ነው።
- **In Review** — ሰው ሊሰራበት የጀመረ ነው።
- **Resolved** — ተጠናቅቋል።

አስተዳዳሪ ምላሽ ከሰጠ በሪፖርቱ ውስጥ ማንበብ ትችላለህ። ይህ ምላሽ ደግሞ የተመሰጠረ ነው።

## መለያህን ማስተካከል

በ**Settings** ውስጥ ትችላለህ፦

- ኢሜል እና ስምህን ማስተካከል
- PIN ወይም ባዮሜትሪክ መቀየር
- የመለያ እንቅስቃሴ መመልከት
- የተከፈቱ መሳሪያዎችን መቆጣጠር

## መግባት ባልችልስ?

- **PIN ረሳሁ** — **Forgot PIN** ጠቅ አድርግ እና በኢሜል የሚላከውን መመሪያ ተከተል።
- **መለያ ታጅዷል** — አስተዳዳሪህን ለማነጋገር ሞክር።
- **አዲስ መሳሪያ** — አዲስ መሳሪያን በደህነት ከመለያህ ጋር መያዝ ያስፈልግሃል። በመግቢያው ላይ **Add Device** ምረጥ።
